# 📖 Лекция 24: Строки (Strings)

## 📝 О чем это
Строки в Python — это **неизменяемые** последовательности символов (Unicode). Понимание того, как они хранятся и как с ними эффективно работать, критично для большинства алгоритмических задач.

## 💡 Основные концепции
*   **Неизменяемость**: При любом изменении строки создается новая.
*   **Срезы (Slicing)**: Очень мощный и быстрый способ извлечения подстрок.
*   **Методы**: Python предоставляет богатый API (`join`, `split`, `find`, `replace` и т.д.).

## 💻 Базовый код
```python
s = "hello"
# Реверс строки
rev = s[::-1]

# Эффективная конкатенация
words = ["a", "b", "c"]
print("".join(words)) # "abc"
```

## 🚀 Сложность
*   Создание среза: O(k), где k — длина среза.
*   Конкатенация (`+`): O(n+m).
*   `"".join()`: O(n).
