# 📖 Лекция 10: Бинарный поиск (Binary Search)

## 📝 О чем это
Бинарный поиск — алгоритм, который находит элемент в **отсортированном** массиве, многократно деля область поиска пополам. За O(log n) вместо O(n) линейного поиска.

## 💡 Основные концепции
* Диапазон поиска задают две границы `left` и `right`; каждый шаг вычисляется середина `mid`.
* Если `arr[mid] == target` — нашли; если `arr[mid] < target` — сужаемся вправо, иначе влево.
* **Критично:** массив должен быть отсортирован, иначе отбрасывание половины необоснованно.

## 🛠 Применение
* Поиск в отсортированном массиве (индекс элемента).
* Поиск первого/последнего вхождения (варианты с нижними границами).
* Поиск во вращённом массиве (одна половина всегда отсортирована).
* «Поиск по ответу» — бинарный поиск по значению с монотонным предикатом.

## 💻 Базовый код
```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

## 🚀 Сложность (Time/Space Complexity)
| Параметр | Сложность |
|---|---|
| Время | O(log n) |
| Память | O(1) (итеративно) / O(log n) (рекурсивно) |

## 💡 Тонкости и "подводные камни"
1. **Забудьте формулу переполнения**: `mid = left + (right - left) // 2` безопаснее в языках с фиксированной разрядностью.
2. **Границы цикла**: разберитесь, когда `<=`, а когда `<` — зависит от того, включаем ли вы границы в диапазон.
3. **Дубликаты**: классический поиск вернёт какой-то из индексов; если нужен первый/последний — используйте lower_bound/upper_bound.
4. **Вращённый массив**: на каждом шаге определите, какая половина отсортирована (левая или правая).
