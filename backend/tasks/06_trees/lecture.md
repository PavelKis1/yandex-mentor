# 📖 Лекция 06: Деревья (Trees)

## 📝 О чем это
Дерево — это иерархическая структура данных из узлов: один узел является **корнем**, а остальные образуют поддеревья. Бинарные деревья используются в поиске, сортировке, сжатии и парсинге выражений. Смысл дерева — быстрый поиск и поддержка иерархий данных.

## 💡 Основные концепции
* **Бинарное дерево**: каждый узел имеет не более двух потомков — `left` и `right`.
* **Бинарное дерево поиска (BST)**: для любого узла все значения в левом поддереве меньше, а в правом — больше. Это даёт поиск за O(log n) в среднем.
* **Обходы (traversal)** — способы посетить все узлы:
  * **Pre-order** (корень → лево → право): копирование дерева, сериализация.
  * **In-order** (лево → корень → право): по BST даёт отсортированный список.
  * **Post-order** (лево → право → корень): удаление дерева, вычисление поддеревьев.

## 🛠 Популярные операции/приёмы
* `search(value)` в BST — сравнить с корнем и пойти в левое/правое поддерево. O(log n) в среднем.
* `max_depth(root)` — рекурсивно: `0` для пустого, иначе `1 + max(глубинаLeft, глубинаRight)`.
* `is_valid_bst(root)` — рекурсивная проверка с границами `(low, high)` для каждого узла.

## 💻 Базовый код и примеры
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

# Рекурсивный preorder-обход
def preorder(node, acc):
    if node is None:
        return acc
    acc.append(node.val)
    preorder(node.left, acc)
    preorder(node.right, acc)
    return acc
```

## 🚀 Сложность (Time/Space Complexity)
| Операция | Среднее | Худшее |
|---|---|---|
| Поиск в BST | O(log n) | O(n) |
| Вставка в BST | O(log n) | O(n) |
| Обход дерева | O(n) | O(n) |
| Память (рекурсия) | O(log n) | O(n) |

*В худшем случае (вырожденное дерево-цепочка) все операции становятся O(n).*

## 💡 Тонкости и "подводные камни"
1. **Вырожденное дерево**: при вставке по порядку BST превращается в список — поиск падает до O(n). Решение — сбалансированные деревья (AVL, красно-чёрное).
2. **`None`-потомки**: любой узел может не иметь потомков; всегда проверяйте `node is None` до обращения.
3. **inorder-проверка BST**: если inorder-обход не возрастает строго — дерево не BST.
4. **Проверка по границам, а не по соседям**: BST требует, чтобы ВСЕ значения левого поддерева были меньше корня, а не только непосредственные дети.
