# 📖 Лекция 03: Стеки (Stacks)

## 📝 О чем это
Стек — это структура данных типа **LIFO** (Last In, First Out — «последним пришёл, первым ушёл»). Представьте стопку тарелок или историю прокрутки в браузере: вы всегда добавляете и берёте элемент сверху. Стек лежит в основе работы функций (call stack), парсера выражений, алгоритма поиска в глубину и многих задач на собеседовании.

## 💡 Основные концепции
В Python стек удобно реализовать обычным `list`, работая только с его концом:
* `list.append(x)` — аналог `push`: положить элемент на вершину. Амортизированное O(1).
* `list.pop()` — аналог `pop`: снять элемент с вершины. O(1).
* `stack[-1]` — аналог `peek`: посмотреть верхний элемент, не удаляя его. O(1).

Стек работает корректно, поскольку `append`/`pop` оперируют концом списка, а не началом (операции с началом, например `pop(0)`, стоили бы O(n)).

## 🛠 Популярные методы
* `stack.append(x)` — добавить на вершину.
* `stack.pop()` — удалить и вернуть элемент с вершины (ошибка на пустом стеке).
* `stack[-1]` — прочитать верхний элемент (peek) без удаления.
* `len(stack)` — текущий размер.
* `is_empty` приём: `if not stack:` — проверка пустоты перед `pop`.

## 💻 Базовый код и примеры
```python
stack = []
stack.append(1)
stack.append(2)
print(stack.pop())  # 2 — LIFO
print(stack[-1])    # 1 — peek

# Проверка симметричности на стеке
s = []
for ch in "abc":
    s.append(ch)
rev = [s.pop() for _ in range(len(s))]
print(rev)          # ['c', 'b', 'a']
```

## 🚀 Сложность (Time/Space Complexity)
| Операция | Сложность |
|---|---|
| Push (append) | O(1) амортизированно |
| Pop | O(1) |
| Peek (stack[-1]) | O(1) |
| Поиск элемента | O(n) |

## 💡 Тонкости и "подводные камни"
1. **Пустой стек**: `stack.pop()` и `stack[-1]` на пустом стеке бросают `IndexError` — всегда проверяйте `if stack:`.
2. **Монотонный стек**: для задач «следующий больший элемент» храните индексы в стеке и сравнивайте вершину с текущим элементом — получается O(n).
3. **Замена `/` на целочисленное деление**: в задачах вроде RPN деление «с усечением к нулю» требует `int(a / b)`, а не `a // b` (для отрицательных чисел они отличаются).
4. **Число в стеке как строки**: если операнды приходят строками, конвертируйте их в `int` при добавлении, а не при каждом сравнении.
