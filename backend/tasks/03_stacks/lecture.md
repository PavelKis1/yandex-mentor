# 📖 Лекция 03: Стеки (Stacks)

## 📝 О чем это
Стек — это структура данных типа **LIFO** (Last In, First Out — "последним пришел, первым ушел"). Представьте стопку тарелок: вы добавляете и берете тарелку только сверху.

## 💡 Основные концепции
В Python стек обычно реализуется через стандартный `list`.
*   `list.append()` — аналог `push` (добавление).
*   `list.pop()` — аналог `pop` (удаление).
Обе операции имеют амортизированную сложность O(1).

*Примечание*: Для реализации очереди с двусторонним доступом лучше использовать `collections.deque`, но для стека `list` вполне достаточно.

## 🛠 Популярные методы
*   `stack.append(x)`: Добавить на вершину.
*   `stack.pop()`: Удалить с вершины.
*   `stack[-1]`: Посмотреть верхний элемент (peek) без удаления.

## 💻 Базовый код
```python
stack = []
stack.append(1)
stack.append(2)
print(stack.pop()) # 2
```

## 🚀 Сложность
| Операция | Сложность |
|---|---|
| Push | O(1) |
| Pop | O(1) |
| Peek | O(1) |
