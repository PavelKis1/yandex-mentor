# 📖 Лекция 11: Префиксные суммы (Prefix Sums)

## 📝 О чем это
Префиксные суммы — это техника оптимизации запросов к диапазонам массива. Вместо суммирования элементов в диапазоне `[i, j]` за O(n), мы используем массив префиксных сумм, чтобы получать ответ за O(1).

## 💡 Основные концепции
Идея заключается в создании массива `P`, где `P[i]` — сумма элементов от начала массива до индекса `i`. Сумма диапазона `[i, j]` вычисляется как `P[j] - P[i-1]`.

## 💻 Базовый код
```python
arr = [1, 2, 3, 4]
# P = [0, 1, 3, 6, 10]
P = [0] * (len(arr) + 1)
for i in range(len(arr)):
    P[i+1] = P[i] + arr[i]

def get_sum(l, r): # Сумма от l до r включительно
    return P[r+1] - P[l]
```

## 🚀 Сложность
*   Построение: O(n)
*   Запрос: O(1)
