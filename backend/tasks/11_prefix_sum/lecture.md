# 📖 Лекция 11: Префиксные суммы (Prefix Sums)

## 📝 О чем это
Префиксные суммы — техника оптимизации запросов к диапазонам массива. Вместо суммирования элементов в диапазоне `[i, j]` за O(n), мы заранее строим массив накопленных сумм и отвечаем на каждый запрос за O(1).

## 💡 Основные концепции
* Строим массив `P`, где `P[0] = 0` и `P[i+1] = P[i] + arr[i]`.
* Сумма диапазона `[l, r]` включительно: `P[r+1] - P[l]`.
* Это частный случай обобщённой идеи «префиксных свёрток»: то же можно делать для XOR, произведений и т.п.

## 🛠 Применение
* Быстрые запросы суммы на диапазоне за O(1).
* Подсчёт подмассивов с заданной суммой (в связке со словарём).
* Произведение всех элементов, кроме текущего (префиксное × суффиксное произведение).

## 💻 Базовый код
```python
arr = [1, 2, 3, 4]          # P = [0, 1, 3, 6, 10]
P = [0] * (len(arr) + 1)
for i in range(len(arr)):
    P[i + 1] = P[i] + arr[i]

def get_sum(l, r):          # сумма от l до r включительно
    return P[r + 1] - P[l]
```

## 🚀 Сложность (Time/Space Complexity)
| Операция | Сложность |
|---|---|
| Построение P | O(n) |
| Запрос суммы [l, r] | O(1) |
| Память | O(n) |

## 💡 Тонкости и "подводные камни"
1. **Индексация со смещением**: P длиннее arr на 1 (P[0]=0) — это упрощает запрос `[0, r]`.
2. **Отрицательные числа**: префиксные суммы корректно работают и с ними.
3. **Подмассив с суммой k**: храните в словаре встречаемость префиксов; для текущего префикса `cur` количество искомых = число префиксов, равных `cur - k`.
4. **Произведение без деления**: используйте левое и правое произведения, исключая нули.
