# Лекция: 49 — Docker Compose (Оркестрация многоконтейнерных приложений)

## Обзор темы
Docker Compose — инструмент для определения и запуска многоконтейнерных приложений Docker с помощью единого конфигурационного файла формата YAML (`docker-compose.yml`).

---

## Подробный теоретический минимум

### 1. Основные концепции
- **Services (Сервисы)**: отдельные контейнеры, составляющие приложение (например, `web`, `database`, `redis`).
- **Networks (Сети)**: виртуальные сети для изоляции и связи контейнеров между собой (сервисы могут обращаться друг к другу по именам контейнеров как по хостам).
- **Volumes (Тома)**: механизмы персистентного хранения данных, защищающие базы данных от потери информации при перезапуске контейнеров.

---

## Производственный пример кода

Пример конфигурационного файла `docker-compose.yml` для FastAPI приложения и базы данных PostgreSQL:

```yaml
version: '3.8'

services:
  web:
    build: .
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://user:password@db:5432/app_db
    depends_on:
      - db

  db:
    image: postgres:15-alpine
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
      POSTGRES_DB: app_db
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

## Анализ сложности (Big O)

- Упрощает локальную разработку и тестирование сложных распределенных систем с $O(1)$ затратами на поднятие окружения одной командой `docker compose up`.

---

## Применение в Яндексе
- **Локальная разработка (Local Development)**: Разработчики поднимают полный стек (бэкенд, базы данных, кэши, очереди) на своих ноутбуках одной командой.
- **Интеграционное тестирование**: Запуск изолированных окружений в CI/CD пайплайнах.
