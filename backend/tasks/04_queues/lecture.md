# 📖 Лекция 04: Очереди (Queues)

## 📝 О чем это
Очередь — это структура данных типа **FIFO** (First In, First Out — «первым пришёл, первым ушёл»), как очередь в магазине или в банке. Она незаменима при обработке задач в порядке поступления: задания, сообщения, сетевые пакеты, обходы графов в ширину (BFS).

## 💡 Основные концепции
Обычный `list` плохо подходит для очереди, потому что удаление первого элемента (`list.pop(0)`) сдвигает все элементы и стоит O(n). Поэтому правильная реализация — `collections.deque`:
* `dq.append(x)` — добавить в конец (enqueue). O(1).
* `dq.popleft()` — достать из начала (dequeue). O(1).
* `deque` (double-ended queue) умеет такие же операции и с другого конца, что даёт гибкость.

## 🛠 Популярные методы
* `dq.append(x)` — добавить элемент в конец.
* `dq.popleft()` — удалить и вернуть элемент из начала.
* `dq[0]` — посмотреть первый элемент (front) без удаления.
* `len(dq)` — текущее количество элементов.
* `dq.rotate(-k)` — сдвинуть элементы (удобно для имитации круга/кольца).

## 💻 Базовый код и примеры
```python
from collections import deque
q = deque()
q.append(1)
q.append(2)
first = q.popleft()  # 1 — дежурим первым

# Обход «по кругу»: перемещаем голову
q = deque([1, 2, 3])
q.rotate(-1)         # [2, 3, 1]
print(q[0])          # 2
```

## 🚀 Сложность (Time/Space Complexity)
| Операция | Сложность (deque) |
|---|---|
| Enqueue (append) | O(1) |
| Dequeue (popleft) | O(1) |
| Front (dq[0]) | O(1) |
| list.pop(0) (так нельзя) | O(n) |

## 💡 Тонкости и "подводные камни"
1. **Пустая очередь**: `popleft()` на пустом deque бросает `IndexError`; проверяйте `if dq:`.
2. **НЕ используйте list как очередь**: `pop(0)`/`insert(0, ...)` стоят O(n) — при больших n это катастрофа по времени.
3. **rotate делает копию**: `dq.rotate` выполняется за O(k)… фактически за O(min(k, n)) — учитывайте при имитации круга.
4. **Монотонная очередь**: храните индексы в порядке убывания значений — так максимум окна всегда на фронте.
