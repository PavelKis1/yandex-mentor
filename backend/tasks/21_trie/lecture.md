# 📖 Лекция 21: Префиксное дерево (Trie)

## 📝 О чем это
Древовидная структура данных для эффективного хранения и поиска строк.

## 🛠 Популярные методы
- `insert(word)`: вставка слова.
- `search(word)`: поиск слова.
- `startsWith(prefix)`: проверка префикса.
