# 📖 Лекция 18: DFS (Depth-First Search)

## 📝 О чем это
Поиск в глубину (DFS) — алгоритм обхода графа, углубляющийся максимально далеко по ветке перед возвратом.

## 🛠 Популярные методы
- Рекурсивная реализация.
- Стек (для итеративной реализации).
