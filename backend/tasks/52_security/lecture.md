# Лекция: 52 — Веб-безопасность и OWASP Top 10

## Обзор темы
Обеспечение безопасности веб-приложений и защита от актуальных уязвимостей (OWASP Top 10) — важнейший аспект проектирования и разработки надежного бэкенда.

---

## Подробный теоретический минимум

### 1. Основные уязвимости и защита
- **SQL-инъекции (SQLi)**: возникают при конкатенации строк в SQL-запросах. Защита: использование параметризованных запросов и ORM.
- **Межсайтовый скриптинг (XSS)**: внедрение вредоносного JS-кода в страницы. Защита: экранирование вывода и CSP (Content Security Policy).
- **Подделка межсайтовых запросов (CSRF)**: выполнение нежелательных действий от имени авторизованного пользователя. Защита: CSRF-токены и `SameSite` куки.

### 2. Аутентификация и авторизация
- **JWT (JSON Web Token)**: безгосударственные токены доступа с цифровой подписью.
- **Хеширование паролей**: использование надежных алгоритмов с «солью» (Argon2, bcrypt, scrypt). Никогда не храните пароли в открытом виде или в MD5/SHA256!

---

## Производственный пример кода

Пример безопасного хеширования пароля с использованием библиотеки `passlib` (bcrypt):

```python
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(password: str) -> str:
    return pwd_context.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

if __name__ == "__main__":
    hashed = hash_password("secure_password123")
    assert verify_password("secure_password123", hashed) is True
    print("Проверка хеширования пароля прошла успешно!")
```
