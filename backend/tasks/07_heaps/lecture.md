# 📖 Лекция 07: Кучи (Heaps)

## 📝 О чем это
Куча (heap) — специализированная структура на основе бинарного дерева, поддерживающая **свойство кучи**: родитель всегда ≤ потомков (min-куча) или ≥ потомков (max-куча). Благодаря этому корень за O(1) отдаёт минимальный (или максимальный) элемент, а вставка и извлечение работают за O(log n). Кучи идеальны для приоритетных очередей и задач «топ-K».

## 💡 Основные концепции
* Куча хранит элементы в виде дерева, но реализуется обычным списком: `heap[0]` — корень (минимум в min-куче).
* В Python модуль `heapq` реализует **min-кучу**. Для max-кучи хранят `-value` или кортежи с отрицательным приоритетом.
* Высоты кучи из n элементов — O(log n), поэтому подъём/погружение одного узла занимает O(log n).

## 🛠 Популярные методы
* `heapq.heappush(heap, item)` — вставить элемент. O(log n).
* `heapq.heappop(heap)` — извлечь минимальный элемент. O(log n).
* `heapq.heapify(list)` — преобразовать список в кучу на месте. O(n).
* `heapq.nlargest(k, iterable)` / `nsmallest` — удобные обёртки для топ-K.
* `heap[0]` — посмотреть минимум без извлечения. O(1).

## 💻 Базовый код и примеры
```python
import heapq
heap = []
heapq.heappush(heap, 10)
heapq.heappush(heap, 5)
heapq.heappush(heap, 8)
min_val = heapq.heappop(heap)   # 5
peek = heap[0]                  # 8

# Топ-2 наибольших за O(n log k)
nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
top2 = heapq.nlargest(2, nums)  # [9, 6]
```

## 🚀 Сложность (Time/Space Complexity)
| Операция | Сложность |
|---|---|
| Просмотр min (heap[0]) | O(1) |
| heappush / heappop | O(log n) |
| heapify | O(n) |
| Память | O(n) |

## 💡 Тонкости и "подводные камни"
1. **Только min-куча**: heapq не даёт max-кучу напрямую — либо храните отрицательные значения, либо пишите свою логику.
2. **Не изменяйте кучу индексами**: любые изменения, кроме через heappush/heappop, нарушают свойство кучи.
3. **Порядок в кортежах**: при хранении `(value, index)` сравнение идёт по первому элементу — продумайте приоритет.
4. **top-k через фиксированный размер**: min-куча размера k хранит наибольшие: при новом элементе, если он больше корня, заменяем корень (heappushpop).
