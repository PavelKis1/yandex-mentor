# Лекция: 54 — Диагностика сети в Linux (ss, netstat, tcpdump)

## Обзор темы
Диагностика сетевых соединений, проверка открытых портов и анализ сетевого трафика необходимы для отладки взаимодействия между микросервисами.

---

## Подробный теоретический минимум

### 1. Утилиты диагностики
- **`ss` / `netstat`**: просмотр активных сетевых соединений, прослушиваемых портов (`LISTEN`) и статистики сокетов.
- **`curl` / `nc` (netcat)**: проверка доступности эндпоинтов и портов.
- **`tcpdump`**: сниффер сетевых пакетов для глубокого анализа трафика на уровне интерфейсов.

---

## Производственный пример кода

Проверка, какой процесс слушает порт 8000 с помощью `ss`:

```bash
ss -tulpn | grep 8000
```

---

## Применение в Яндексе
- **Инфраструктурный траблшутинг**: Диагностика проблем сетевых таймаутов, разрывов соединений между бэкендом и базами данных.
