# 📖 Лекция 09: Два указателя (Two Pointers)

## 📝 О чем это
Метод двух указателей эффективно решает задачи на отсортированных массивах, уменьшая временную сложность с O(n²) до O(n).

## 💡 Основные концепции
*   Указатели обычно располагаются в начале и в конце массива (`left` и `right`).
*   В зависимости от условия задачи, мы двигаем их навстречу друг другу или в одном направлении.

## 🛠 Применение
*   Поиск пары чисел, дающих заданную сумму (Two Sum в отсортированном массиве).
*   Проверка, является ли строка палиндромом.
*   Удаление дубликатов из отсортированного массива.

## 💻 Базовый код
```python
def two_sum(arr, target):
    left, right = 0, len(arr) - 1
    while left < right:
        s = arr[left] + arr[right]
        if s == target: return True
        elif s < target: left += 1
        else: right -= 1
    return False
```

## 🚀 Сложность
*   O(n).
