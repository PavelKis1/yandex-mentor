# 📖 Лекция 09: Два указателя (Two Pointers)

## 📝 О чем это
Метод двух указателей эффективно решает задачи на отсортированных массивах и строках, уменьшая временную сложность с O(n²) до O(n). Вместо вложенных циклов мы поддерживаем два индекса и двигаем их в зависимости от текущего сравнения.

## 💡 Основные концепции
* Указатели обычно располагаются в начале и в конце массива (`left` и `right`) и движутся навстречу друг другу.
* Для задач «на одном массиве в одном направлении» используют быстрый и медленный указатели (`fast`/`slow`).
* Ключевое преимущество — каждый элемент посещается не более одного раза за проход.

## 🛠 Применение
* Поиск пары чисел, дающих заданную сумму (Two Sum на отсортированном массиве).
* Проверка, является ли строка палиндромом.
* Удаление дубликатов из отсортированного массива in-place.
* Задача о контейнере с наибольшим количеством воды.

## 💻 Базовый код
```python
# Два указателя с краёв: поиск пары с заданной суммой
def two_sum_pair(arr, target):
    left, right = 0, len(arr) - 1
    while left < right:
        s = arr[left] + arr[right]
        if s == target:
            return [arr[left], arr[right]]
        elif s < target:
            left += 1      # сумма мала — нужен больший элемент
        else:
            right -= 1     # сумма велика — нужен меньший элемент
    return []

# Удаление дубликатов in-place (возвращает длину уникальной части)
def remove_duplicates(nums):
    if not nums:
        return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1
```

## 🚀 Сложность (Time/Space Complexity)
| Параметр | Сложность |
|---|---|
| Время | O(n) — указатели проходят массив один раз |
| Память | O(1) — дополнительные структуры не нужны |

## 💡 Тонкости и "подводные камни"
1. **Работает на отсортированных данных**: идея движения указателей опирается на монотонность.
2. **Не выходите за границы**: проверяйте условие `left < right` в каждом цикле.
3. **In-place**: при удалении дубликатов важно не потерять длину новой «активной» части — возвращайте её явно.
4. **В задаче с водой**: всегда двигайте указатель с меньшим столбом, чтобы не терять потенциальные максимумы.
