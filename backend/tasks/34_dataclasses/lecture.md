# Лекция: 34 — Dataclasses (Датаклассы в Python)

## Обзор темы
Модуль `dataclasses` (появившийся в Python 3.7) предоставляет декоратор и функции для автоматической генерации специальных методов (`__init__`, `__repr__`, `__eq__`, `__lt__` и др.) для классов, которые в первую очередь хранят данные.

---

## Подробный теоретический минимум

### 1. Декоратор `@dataclass`
Избавляет разработчика от написания шаблонного кода (`boilerplate`) для инициализации объектов.
- По умолчанию генерирует методы `__init__`, `__repr__` (удобный вывод в консоль) и `__eq__` (сравнение по полям).
- Поддерживает параметр `frozen=True`, который делает объект неизменяемым (`immutable`). За попытку изменить поле после создания будет выброшено исключение `FrozenInstanceError`.

### 2. Функция `field()`
Позволяет тонко настроить поведение отдельных полей датакласса:
- **`default` / `default_factory`**: задание значений по умолчанию (для изменяемых типов, таких как `list` или `dict`, обязательно использовать `default_factory=list`, чтобы избежать разделения общего состояния между экземплярами).
- **`init=False`**: исключает поле из сгенерированного метода `__init__` (например, для вычисляемых полей).
- **`repr=False`**: скрывает поле при выводе объекта в консоль.

---

## Производственный пример кода

Пример описания неизменяемой конфигурации микросервиса с валидацией в `__post_init__`:

```python
from dataclasses import dataclass, field
from typing import List

@dataclass(frozen=True)
class ServiceConfig:
    host: str
    port: int
    allowed_ips: List[str] = field(default_factory=list)

    def __post_init__(self):
        if not (1 <= self.port <= 65535):
            raise ValueError(f"Invalid port number: {self.port}")

if __name__ == "__main__":
    config = ServiceConfig(host="0.0.0.0", port=9000, allowed_ips=["127.0.0.1"])
    print(config)
    
    # Проверка неизменяемости
    try:
        config.port = 80  # type: ignore
    except Exception as e:
        print(f"Caught expected frozen error: {e.__class__.__name__}")
    
    print("Датаклассы успешно проверены!")
```

## Анализ сложности (Big O)

| Операция | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **Инициализация объекта** | $O(K)$ | $O(K)$ | $K$ — количество полей датакласса. |
| **Сравнение (`__eq__`)** | $O(K)$ | $O(1)$ | Поочередное сравнение всех полей. |

## Применение в Яндексе
- **DTO и схемы данных**: Описание контрактов взаимодействия между микросервисами.
- **Конфигурации**: Хранение настроек приложений, прочитанных из环境变量 или YAML-файлов.
- **Доменные модели**: Представление сущностей бизнеса в бэкенд-логике.
