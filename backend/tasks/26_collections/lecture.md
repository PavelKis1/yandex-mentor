# Лекция: 26 — collections (Специализированные контейнеры данных)

## Обзор темы
Модуль `collections` в стандартной библиотеке Python предоставляет специализированные контейнеры данных, которые расширяют возможности встроенных структур (`dict`, `list`, `set`, `tuple`). Знание этих структур — базовый навык для успешного прохождения секции алгоритмов и системного дизайна на собеседованиях в Яндекс.

---

## Подробный теоретический минимум

### 1. Counter (Мультимножество)
`Counter` — это подкласс словаря (`dict`), предназначенный для подсчета хэшируемых объектов. Элементы хранятся как ключи словаря, а их количество — как значения.
- **Особенности**: Поддерживает арифметические операции над мультимножествами (`+`, `-`, `&`, `|`), а также методы `.most_common(n)` для получения топ-N элементов.
- **Под капотом**: Наследуется от `dict`, оптимизирован для быстрого подсчета частот за счет реализации на языке C.

### 2. defaultdict (Словарь со значением по умолчанию)
Обычный словарь в Python вызывает ошибку `KeyError`, если ключ отсутствует. `defaultdict` принимает фабрику (`int`, `list`, `set`, `dict` или лямбду), которая автоматически создает значение для несуществующего ключа.
- **Важно на практике**: Идеально подходит для группировки данных (например, `defaultdict(list)`) без необходимости использовать конструкцию `dict.setdefault()` или проверять ключ через `if key in d`.

### 3. deque (Двусторонняя очередь)
Встроенный тип `list` оптимизирован для быстрого доступа по индексу, но вставка или удаление элементов в начале списка требует сдвига всех остальных элементов со сложностью $O(N)$.
- **deque** (Double Ended Queue) спроектирована для эффективных операций добавления и удаления с обоих концов со сложностью $O(1)$.
- **Под капотом**: Реализована как кольцевой буфер на основе блоков памяти, что исключает затраты на аллокацию при изменении размера.

### 4. namedtuple (Именованный кортеж)
Фабрика для создания подклассов кортежей с именованными полями.
- **Преимущества**: Позволяет обращаться к элементам по имени (как у объектов или словарей), но сохраняет неизменяемость (`immutable`) и легковесность обычного кортежа (нет словаря `__dict__` на каждый экземпляр).

## Производственный пример кода

Ниже приведен production-ready пример решения типичной задачи бэкенда: анализа логов доступа и поиска топ-IP адресов с использованием `Counter` и группировки эндпоинтов через `defaultdict`.

```python
from collections import Counter, defaultdict
from typing import List, Tuple

def analyze_access_logs(logs: List[str]) -> Tuple[str, dict]:
    """
    Анализирует лог-файл доступа.
    Формат лога: '192.168.1.1 GET /api/v1/users 200'
    Возвращает самый частый IP и статистику запросов по эндпоинтам.
    """
    ip_counter = Counter()
    endpoint_by_status = defaultdict(list)
    
    for line in logs:
        parts = line.strip().split()
        if len(parts) < 4:
            continue
        ip, method, path, status = parts[0], parts[1], parts[2], parts[3]
        
        ip_counter[ip] += 1
        endpoint_by_status[status].append(f"{method} {path}")
        
    top_ip = ip_counter.most_common(1)[0][0] if ip_counter else ""
    return top_ip, dict(endpoint_by_status)

if __name__ == "__main__":
    sample_logs = [
        "192.168.1.10 GET /api/v1/ping 200",
        "192.168.1.11 POST /api/v1/users 201",
        "192.168.1.10 GET /api/v1/ping 200",
        "192.168.1.15 GET /api/v1/items 404",
    ]
    
    top_ip, stats = analyze_access_logs(sample_logs)
    print(f"Top IP: {top_ip}")
    print(f"Stats by status: {stats}")
    
    assert top_ip == "192.168.1.10"
    print("Тесты пройдены успешно!")
```

## Анализ сложности (Big O)

| Структура / Метод | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **Counter.most_common(k)** | $O(N + K \log N)$ | $O(N)$ | $N$ — число уникальных ключей, $K$ — число возвращаемых элементов. |
| **defaultdict[key]** | $O(1)$ в среднем | $O(N)$ | Поиск и вставка ключа выполняются за константное время. |
| **deque.appendleft() / popleft()** | $O(1)$ | $O(N)$ | Добавление и удаление с краев оптимизировано на уровне CPython. |

## Применение в Яндексе
- **Поиск и реклама**: Быстрый подсчет термов, частых запросов и кликов в реальном времени с помощью `Counter`.
- **Маркет и Такси**: Обработка очередей заказов и сообщений в шинах данных через `deque`.
- **Логирование и мониторинг**: Индексация метрик и агрегация ошибок по статус-кодам с использованием `defaultdict`.
