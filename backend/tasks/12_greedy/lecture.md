# 📖 Лекция 12: Жадные алгоритмы (Greedy Algorithms)

## 📝 О чем это
Жадный алгоритм на каждом шаге делает локально оптимальный выбор, надеясь, что в итоге придет к глобальному оптимуму.

## 💡 Основные концепции
Применяются, когда задача обладает свойством жадного выбора и оптимальной подструктуры. Часто используются для оптимизации ресурсов, расписаний и задач упаковки.

## 💻 Базовый код
```python
# Задача о размене монет (жадный подход)
def coin_change(amount, coins):
    coins.sort(reverse=True)
    count = 0
    for coin in coins:
        count += amount // coin
        amount %= coin
    return count
```

## 🚀 Сложность
*   Зависит от задачи, часто O(n log n) из-за сортировки.
