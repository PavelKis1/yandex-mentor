# 📖 Лекция 12: Жадные алгоритмы (Greedy Algorithms)

## 📝 О чем это
Жадный алгоритм на каждом шаге делает **локально оптимальный выбор**, надеясь, что это приведёт к глобальному оптимуму. Это работает только для задач со свойством «жадного выбора» и оптимальной подструктурой.

## 💡 Основные концепции
* Применяется, когда локально-оптимальный шаг не исключает достижение глобального оптимума.
* Часто не требует вспомогательных структур — достаточно одного прохода.
* Для интервалов типично требуется предварительная сортировка (O(n log n)).

## 🛠 Применение
* Jump Game — поддержание максимальной достижимой позиции.
* Gas Station — поиск стартовой станции по суммарному запасу топлива.
* Наложение/удаление пересекающихся интервалов — сортировка по правой границе.
* Задачи о размене, расписаниях и упаковке.

## 💻 Базовый код
```python
def can_jump(nums):
    max_reach = 0
    for i, jump in enumerate(nums):
        if i > max_reach:
            return False
        max_reach = max(max_reach, i + jump)
    return True

# Интервалы: минимальное число удалений для непересекаемости
def erase_overlap_intervals(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev = 0, float("-inf")
    for start, end in intervals:
        if start >= prev:
            prev = end
        else:
            count += 1
    return count
```

## 🚀 Сложность (Time/Space Complexity)
| Параметр | Сложность |
|---|---|
| Время | O(n) или O(n log n) (после сортировки) |
| Память | O(1) |

## 💡 Тонкости и "подводные камни"
1. **Жадность не всегда оптимальна**: например, задача о размене монет с нестандартными номиналами ломает жадный подход — нужен DP.
2. **Интервалы**: сортируйте по **правой** границе, чтобы оставлять «самые ранние» интервалы.
3. **Jump Game**: учитываете ли вы, что достижение `i` может требовать промежуточных шагов? max_reach решает это автоматически.
4. **Gas Station**: если суммарного топлива хватает, ответ сущестствует и находится одним проходом.
