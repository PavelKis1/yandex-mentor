# 📖 Лекция 23: Битовые операции (Bitwise Operations)

## 📝 О чем это
Битовые операции — это работа непосредственно с битами целых чисел. Это один из самых быстрых способов манипуляции данными, незаменимый в задачах на оптимизацию.

## 💡 Основные концепции
*   **AND (&)**: 1, если оба бита 1.
*   **OR (|)**: 1, если хотя бы один бит 1.
*   **XOR (^)**: 1, если биты разные.
*   **NOT (~)**: Инверсия всех битов.
*   **Сдвиги (<<, >>)**: Умножение/деление на степени двойки.

## 💻 Базовый код
```python
# Проверка, является ли число степенью двойки
def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0

# Умножение на 2
x = 5
print(x << 1) # 10
```

## 🚀 Сложность
Все операции работают за O(1), так как размер целого числа (обычно 32 или 64 бита) ограничен.
