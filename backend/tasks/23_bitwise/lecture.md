# 📖 Лекция 23: Битовая арифметика (Bitwise)

## Что это и зачем

Битовые операции работают с двоичным представлением чисел. Они очень быстрые (O(1)) и используются для оптимизации, шифрования, хеширования.

## Основные операции

```python
# AND (&) — оба бита 1
5 & 3  # 101 & 011 = 001 = 1

# OR (|) — хотя бы один 1
5 | 3  # 101 | 011 = 111 = 7

# XOR (^) — разные биты
5 ^ 3  # 101 ^ 011 = 110 = 6

# NOT (~) — инверсия
~5     # ...11111010 (в Python — отрицательное число)

# Сдвиг влево (<<) — умножение на 2^k
5 << 1  # 10 (5 * 2)

# Сдвиг вправо (>>) — деление на 2^k
5 >> 1  # 2 (5 // 2)
```

## Полезные трюки

**Проверка чётности:**
```python
def is_even(n):
    return (n & 1) == 0
```

**Получение последнего бита:**
```python
last_bit = n & 1
```

**Удаление последнего бита 1:**
```python
n = n & (n - 1)  # 1100 → 1000
```

**Проверка степени двойки:**
```python
def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0
```

**Подсчёт установленных битов:**
```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

**Single Number (XOR):**
```python
def single_number(nums):
    result = 0
    for num in nums:
        result ^= num
    return result
```

**Два Single Numbers:**
```python
def single_number_iii(nums):
    xor_all = 0
    for num in nums:
        xor_all ^= num
    
    # Найти любой установленный бит
    diff = xor_all & (-xor_all)
    
    a = b = 0
    for num in nums:
        if num & diff:
            a ^= num
        else:
            b ^= num
    return [a, b]
```

- **Шифрование** — XOR в простых шифрах

## Подводные камни

- `~` в Python даёт отрицательное число (бесконечная длина)
- `n & (n - 1)` удаляет только один бит
- Не проверил `n > 0` для степени двойки
