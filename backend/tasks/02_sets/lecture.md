# 📖 Лекция 02: Множества (Sets)

## 📝 О чем это
Множества (`set`) — это контейнеры для хранения **уникальных** элементов. В отличие от словарей, они не хранят пары "ключ-значение", а только ключи. Они жизненно необходимы для задач на дедупликацию, проверку наличия (membership test) и математических операций над множествами.

## 💡 Основные концепции
Множества в Python реализованы как хеш-таблицы (аналогично ключам `dict`).

*   **Уникальность**: Попытка добавить дубликат игнорируется.
*   **Хешируемость**: Как и ключи словаря, элементы множества должны быть хешируемыми (неизменяемыми).
*   **Математические операции**: Множества поддерживают операции объединения, пересечения, разности и симметричной разности, которые реализованы крайне эффективно.

## 🛠 Популярные методы
*   `s.add(x)`: Добавляет элемент. O(1).
*   `s.remove(x)` / `s.discard(x)`: `remove` вызывает KeyError, если элемента нет; `discard` — безопасен.
*   `s.union(other)`, `s.intersection(other)`, `s.difference(other)`: Методы для операций над множествами. Можно использовать операторы `|`, `&`, `-`, `^`.
*   `s.pop()`: Удаляет и возвращает произвольный элемент.

## 💻 Базовый код
```python
# Дедупликация
arr = [1, 2, 2, 3]
unique = set(arr) # O(n)

# Операции
s1 = {1, 2, 3}
s2 = {3, 4, 5}
print(s1 & s2)  # {3} - пересечение
print(s1 | s2)  # {1, 2, 3, 4, 5} - объединение
```

## 🚀 Сложность
| Операция | Среднее | Худшее |
|---|---|---|
| Поиск `x in s` | O(1) | O(n) |
| Вставка | O(1) | O(n) |
| Пересечение | O(min(len(s1), len(s2))) | - |
