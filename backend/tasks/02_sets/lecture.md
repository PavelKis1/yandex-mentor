# 📖 Лекция 02: Множества (Sets)

## 📝 О чем это
Множество (`set`) — это контейнер для хранения **уникальных** элементов, реализованный в Python поверх хеш-таблицы (открытая адресация). В отличие от словаря, оно хранит не пары «ключ-значение», а только ключи. Множества незаменимы там, где нужно быстро проверять наличие элемента, убирать дубликаты или выполнять математические операции над коллекциями: пересечение, объединение, разность.

## 💡 Основные концепции
1. **Уникальность**: Попытка добавить уже существующий элемент игнорируется — дубликатов в множестве не бывает по определению.
2. **Хешируемость**: Как и ключи `dict`, элементы множества должны быть хешируемыми (неизменяемыми). Значит, элементом может быть `int`, `str`, `tuple`, но не `list` или `set`.
3. **Хеш-таблица внутри**: Поиск, добавление и удаление выполняются за ожидаемое O(1): команда `x in s` идёт через хеш-функцию, а не линейное сравнение со всеми элементами.
4. **Теоретико-множественные операции**: `|` — объединение, `&` — пересечение, `-` — разность, `^` — симметрическая разность. Это быстрые операции, на которых строится решение многих задач.

## 🛠 Популярные методы
* `s.add(x)` — добавить элемент. O(1) в среднем.
* `s.discard(x)` и `s.remove(x)` — удалить элемент; `discard` не бросает ошибку, если элемента нет, а `remove` бросает `KeyError`.
* `s.pop()` — удалить и вернуть произвольный элемент (на пустом множестве бросает `KeyError`).
* `s.union(other)`, `s.intersection(other)`, `s.difference(other)` — методы-аналоги операторов `|`, `&`, `-`.
* `len(s)` — количество уникальных элементов. O(1).

## 💻 Базовый код и примеры
```python
# Дедупликация массива
arr = [1, 2, 2, 3, 3, 3]
unique = list(set(arr))  # [1, 2, 3] — порядок не гарантирован

# Быстрая проверка наличия
seen = {1, 2, 3}
print(2 in seen)   # True, O(1)

# Операции над множествами
a = {1, 2, 3}
b = {3, 4, 5}
print(a & b)   # {3}                 пересечение
print(a | b)   # {1, 2, 3, 4, 5}     объединение
print(a - b)   # {1, 2}              разность
```

## 🚀 Сложность (Time/Space Complexity)
| Операция | Среднее | Худшее |
|---|---|---|
| `x in s` (поиск) | O(1) | O(n) |
| Вставка / удаление | O(1) | O(n) |
| `s1 & s2` (пересечение) | O(min(len(s1), len(s2))) | — |

*Худшее O(n) достигается при массовых коллизиях или плохой хеш-функции. Пересечение эффективнее вести по меньшему из множеств.*

## 💡 Тонкости и "подводные камни"
1. **Неизменяемые элементы**: нельзя хранить в `set` списки или другие множества — у них изменяемое содержимое, поэтому хеш можно изменить. Используйте `frozenset` или `tuple`.
2. **Потеря порядка**: перебор `set` не гарантирует порядок вставки (в отличие от `dict` в Python 3.7+). Если порядок важен — нужен список или явная сортировка `sorted(...)`.
3. **Пустое множество**: `{}` создаёт пустой *словарь*, а не множество; для пустого множества используйте `set()`.
4. **Дедупликация ≠ сохранение порядка**: `set(arr)` убирает дубли за O(n), но перемешивает элементы.
