# 📖 Лекция 05: Связные списки (Linked Lists)

## 📝 О чем это
Связный список — это линейная структура данных, где каждый элемент (узел) хранит значение и ссылку на следующий элемент. В отличие от массивов, элементы не лежат в непрерывной области памяти, а «связаны» указателями. Это даёт вставку и удаление за O(1) там, где у массива было бы O(n), но лишает быстрого доступа по индексу (O(n)).

## 💡 Основные концепции
* **Узел (Node)**: базовый элемент со значением (`val`) и указателем на следующий (`next`).
* **Односвязный список**: каждый узел ссылается только на следующий; переход назад невозможен.
* **Двусвязный список**: узлы имеют ссылки и на следующий, и на предыдущий — позволяет двигаться в обе стороны.
* **Кольцевой список**: последний узел ссылается на первый.
* **Head**: указатель на первый узел; пустой список — это `head is None`.

## 🛠 Популярные методы/приёмы
* Вставка в начало — O(1): `new.next = head; head = new`.
* Вставка в конец — O(n), если нет ссылки на хвост (с хвостом — O(1)).
* Удаление по значению — O(n): ищем узел и перевешиваем `prev.next`.
* **Фиктивная голова (dummy node)** — упрощает вставку/удаление в начале.

## 💻 Базовый код и примеры
```python
class ListNode:
    def __init__(self, val=0, nxt=None):
        self.val = val
        self.next = nxt

# Создание списка 1 -> 2 -> 3
nodes = [ListNode(v) for v in (1, 2, 3)]
for a, b in zip(nodes, nodes[1:]):
    a.next = b
head = nodes[0]

# Обход
cur = head
while cur:
    print(cur.val)
    cur = cur.next
```

## 🚀 Сложность (Time/Space Complexity)
| Операция | Сложность |
|---|---|
| Доступ по индексу | O(n) |
| Поиск значения | O(n) |
| Вставка в начало / удаление в начале | O(1) |
| Вставка в конец | O(n) или O(1) с хвостом |

## 💡 Тонкости и "подводные камни"
1. **Не теряйте голову**: при развороте всегда сохраняйте следующий узел до того, как перевесить `next` — иначе обрубите список.
2. **Крайние случаи**: пустой список (`head is None`) и список из одного узла — проверяйте их первыми.
3. **Рекурсия**: рекурсивный разворот проще, но использует O(n) памяти на стек вызовов; итеративно — O(1) памяти.
4. **Корректность при цикле**: обычный обход по циклу зациклится; для детекции используйте алгоритм Флойда или множество посещённых узлов.
