# 📖 Лекция 08: Скользящее окно (Sliding Window)

## 📝 О чем это
Метод скользящего окна используется для решения задач на массивах или строках, где нужно найти подмассив или подстроку, удовлетворяющую заданному условию. Вместо перебора всех подмассивов (O(n²)) мы поддерживаем текущее «окно» двумя указателями и обходим массив за один проход.

## 💡 Основные концепции
* Два указателя `left` и `right` ограничивают текущее окно `arr[left:right]`.
* Двигаем `right` для расширения окна; сдвигаем `left` для сужения, когда условие нарушается.
* Окно бывает **фиксированного размера** (k элементов) или **переменного** (удовлетворяет условию).

## 🛠 Применение
* Поиск максимальной суммы подмассива фиксированной длины k.
* Поиск самой длинной подстроки без повторяющихся символов.
* Поиск минимального окна, содержащего все символы заданной строки t.

## 💻 Базовый код
```python
# Окно фиксированного размера k — максимальная сумма
def max_sum_fixed(arr, k):
    window = sum(arr[:k])
    result = window
    for i in range(len(arr) - k):
        window = window - arr[i] + arr[i + k]   # сдвиг окна вправо
        result = max(result, window)
    return result

# Окно переменного размера — самая длинная подстрока без повторов
def longest_unique(s):
    seen = set()
    left = result = 0
    for right, ch in enumerate(s):
        while ch in seen:          # нарушение условия — сужаем слева
            seen.remove(s[left])
            left += 1
        seen.add(ch)
        result = max(result, right - left + 1)
    return result
```

## 🚀 Сложность (Time/Space Complexity)
| Параметр | Сложность |
|---|---|
| Время | O(n) — каждый элемент входит/выбывает из окна один раз |
| Память | O(1) или O(k) в зависимости от данных окна |

## 💡 Тонкости и "подводные камни"
1. **Инвариант окна**: чётко определите условие, при котором окно считается корректным, и делайте его проверку «на входе» нового элемента.
2. **Не забывайте обновлять left внутри while**: иногда нужно удалять несколько элементов подряд.
3. **Для строк** удобно хранить счётчики символов (Counter), чтобы за O(1) отвечать на «содержит ли окно всё нужное».
4. **Подстрока/подпоследовательность**: окно работает именно с непрерывными подмассивами.
