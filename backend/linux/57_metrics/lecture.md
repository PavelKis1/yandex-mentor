# Лекция: 57 — Метрики и мониторинг (Prometheus, Grafana, RED method)

## Обзор темы
Мониторинг здоровья системы строится на метриках. Инструменты Prometheus и Grafana позволяют собирать числовые показатели работы сервисов в реальном времени и визуализировать их на дашбордах.

---

## Подробный теоретический минимум

### 1. Типы метрик в Prometheus
- **Counter (Счетчик)**: монотонно возрастающая величина (например, количество обработанных запросов).
- **Gauge (Датчик)**: значение, которое может как расти, так и падать (например, текущее использование RAM, количество активных подключений).
- **Histogram (Гистограмма)**: распределение значений по бакетам (используется для измерения времени ответа / латентности).

### 2. Методология RED (для микросервисов)
- **R**ate: количество запросов в секунду (RPS).
- **E**rrors: количество ошибок в секунду.
- **D**uration: время выполнения запросов (латентность, перцентили p95/p99).

---

## Производственный пример кода

Пример создания метрики счетчика с помощью официального клиента Prometheus для Python:

```python
from prometheus_client import Counter, start_http_server
import time

# Определение метрики
REQUEST_COUNT = Counter('http_requests_total', 'Total HTTP Requests', ['method', 'endpoint'])

if __name__ == "__main__":
    # Запуск сервера метрик на порту 8000
    start_http_server(8000)
    print("Metrics server started on port 8000...")
    
    # Имитация работы
    while True:
        REQUEST_COUNT.labels(method='GET', endpoint='/api/v1/ping').inc()
        time.sleep(1)
```
