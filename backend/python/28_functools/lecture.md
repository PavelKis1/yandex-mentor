# Лекция: 28 — functools (Инструменты для работы с функциями)

## Обзор темы
Модуль `functools` содержит инструменты для работы с функциями высшего порядка — функциями, которые принимают или возвращают другие функции. Понимание этих инструментов позволяет писать лаконичный, оптимизированный и декларативный код.

---

## Подробный теоретический минимум

### 1. lru_cache (Мемоизация)
Декоратор, который кэширует результаты вызовов функции. Если функция вызывается повторно с теми же аргументами, результат возвращается из кэша мгновенно.
- **Параметр `maxsize`**: определяет максимальное количество записей в кэше (по умолчанию 128; при `maxsize=None` кэш растет бесконечно).
- **Важно**: аргументы функции должны быть хэшируемыми.

### 2. partial (Частичное применение)
Позволяет зафиксировать часть аргументов функции и получить новый объект, вызываемый с меньшим числом аргументов (уменьшенная арность).
- Удобно для передачи колбэков в функции высшего порядка (например, `map` или `filter`).

### 3. singledispatch (Одиночная диспетчеризация)
Позволяет реализовать generic-функции (перегрузку функций по типу первого аргумента), заменяя громоздкие конструкции из `isinstance()`.

### 4. reduce
Применяет функцию двух аргументов к элементам последовательности слева направо кумулятивно, сводя коллекцию к единственному значению.

---

## Производственный пример кода

Применение `lru_cache` для кэширования результатов конфигурационных вычислений и `partial` для создания специализированных логгеров:

```python
from functools import lru_cache, partial
import time

@lru_cache(maxsize=256)
def fetch_heavy_config(config_id: int) -> dict:
    """Имитация долгого запроса к БД или конфигурационному сервису."""
    time.sleep(0.01)  # Имитация задержки сети
    return {"id": config_id, "status": "active", "rules": [1, 2, 3]}

def log_message(level: str, message: str) -> None:
    print(f"[{level.upper}] {message}")

# Создаем специализированные функции через partial
info_log = partial(log_message, "info")
error_log = partial(log_message, "error")

if __name__ == "__main__":
    # Первый вызов — реальная задержка
    start = time.perf_counter()
    cfg1 = fetch_heavy_config(42)
    t1 = time.perf_counter() - start
    
    # Второй вызов — мгновенно из кэша
    start = time.perf_counter()
    cfg2 = fetch_heavy_config(42)
    t2 = time.perf_counter() - start
    
    info_log(f"Config loaded in {t1:.4f}s, cached in {t2:.4f}s")
    assert cfg1 == cfg2
    print("Тесты functools пройдены!")
```

## Анализ сложности (Big O)

| Инструмент | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **lru_cache** | $O(1)$ для попадания в кэш | $O(K)$ | $K$ — количество записей в кэше (`maxsize`). |
| **partial** | $O(1)$ | $O(1)$ | Создание обертки с фиксированными аргументами. |
| **reduce** | $O(N)$ | $O(1)$ | Проход по всей последовательности элементов. |

## Применение в Яндексе
- **Веб-сервисы**: Кэширование справочников, локальных настроек и результатов частых вычислений.
- **Инфраструктура**: Частичное применение функций при конфигурировании асинхронных воркеров и обработчиков событий.
