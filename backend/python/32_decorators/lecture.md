# Лекция: 32 — Декораторы (Decorators)

## Обзор темы
Декораторы в Python — это мощный инструмент метапрограммирования, основанный на концепции функций высшего порядка. Они позволяют прозрачно модифицировать или расширять поведение функций и классов без изменения их исходного кода.

---

## Подробный теоретический минимум

### 1. Анатомия декоратора
Декоратор принимает функцию в качестве аргумента, определяет внутреннюю функцию-обертку (`wrapper`), добавляет необходимую логику (логирование, кэширование, проверку прав) и возвращает обертку.
- **`functools.wraps`**: обязательный элемент хорошего тона. Он копирует метаданные (`__name__`, `__doc__`, `__annotations__`) из оригинальной функции в обертку, предотвращая поломку документации и интроспекции.

### 2. Декораторы с аргументами (Фабрики декораторов)
Если декоратору требуется принимать параметры (например, `@retry(retries=3)`), создается функция-фабрика верхнего уровня, которая принимает аргументы декоратора и возвращает классический декоратор. Это требует трех уровней вложенности функций.

### 3. Классы как декораторы
Декоратор можно реализовать в виде класса с методом `__call__`. Это удобно, если декоратору нужно сохранять сложное внутреннее состояние (например, счетчик вызовов или статистику ошибок).

## Производственный пример кода

Реализация production-ready декоратора повторных попыток (Retry) с экспоненциальной задержкой:

```python
from functools import wraps
import time
from typing import Callable, Any

def retry(retries: int = 3, delay: float = 0.1) -> Callable:
    def decorator(func: Callable) -> Callable:
        @wraps(func)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            last_exception = None
            for attempt in range(retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last_exception = e
                    time.sleep(delay * (2 ** attempt))
            raise last_exception
        return wrapper
    return decorator

@retry(retries=2, delay=0.01)
def unstable_api_call() -> str:
    # Имитация нестабильного сетевого запроса
    raise ConnectionError("Service unavailable")

if __name__ == "__main__":
    try:
        unstable_api_call()
    except ConnectionError as err:
        print(f"Caught expected error after retries: {err}")
        print("Декоратор retry успешно проверен!")
```

## Анализ сложности (Big O)

| Операция | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **Вызов декорированной функции** | $O(1)$ накладные расходы | $O(1)$ | Выполнение кода обертки перед вызовом оригинала. |

## Применение в Яндексе
- **Веб-разработка**: Маршрутизация эндпоинтов и внедрение зависимостей (`Depends`) в FastAPI.
- **Отказоустойчивость**: Декораторы повторных попыток (`retry`), таймаутов и ограничения частоты запросов (`rate limiter`) при взаимодействии микросервисов.
- **Мониторинг**: Автоматический сбор метрик времени выполнения и статусов ответа для Prometheus.
