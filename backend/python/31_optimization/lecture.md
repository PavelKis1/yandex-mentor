# Лекция: 31 — Оптимизация производительности в Python

## Обзор темы
Python — интерпретируемый язык с динамической типизацией, что накладывает ограничения на скорость выполнения и потребление памяти. Знание техник оптимизации позволяет писать быстрый код, сопоставимый по эффективности с низкоуровневыми языками.

---

## Подробный теоретический минимум

### 1. Использование `__slots__`
По умолчанию каждый экземпляр класса в Python хранит атрибуты в словаре `__dict__`, что удобно, но требует значительных затрат памяти (каждый словарь выделяет память под хэш-таблицу).
- **Механизм**: Объявление `__slots__ = ('attr1', 'attr2')` фиксирует набор атрибутов и заменяет словарь статическим массивом указателей.
- **Эффект**: Экономия до 40–50% оперативной памяти при создании миллионов экземпляров класса и небольшой прирост скорости доступа к полям.

### 2. Ленивые вычисления и генераторы
- Вместо создания больших списков в памяти с помощью списковых включений (`[...]`), использование генераторных выражений (`(...)`) или ключевого слова `yield` позволяет обрабатывать потоки данных с потреблением памяти $O(1)$.

### 3. Оптимизация поиска и работы со структурами
- Замена списков (`list`) на множества (`set`) или словари (`dict`) для проверки принадлежности (`in`) ускоряет поиск с $O(N)$ до $O(1)$.

---

## Производственный пример кода

Сравнение потребления памяти и производительности класса с `__slots__` и без него:

```python
import sys

class StandardClass:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class SlottedClass:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

if __name__ == "__main__":
    std_obj = StandardClass(1, 2)
    slot_obj = SlottedClass(1, 2)
    
    print(f"Standard class size: {sys.getsizeof(std_obj.__dict__) + sys.getsizeof(std_obj)} bytes")
    print(f"Slotted class size: {sys.getsizeof(slot_obj)} bytes")
    print("Оптимизация памяти с __slots__ подтверждена!")
```

---

## Анализ сложности (Big O)

| Техника | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **__slots__** | $O(1)$ (быстрее доступ) | $O(1)$ на объект | Устранение накладных расходов `__dict__`. |
| **Генераторы** | $O(1)$ на итерацию | $O(1)$ | Потоковая обработка без промежуточных коллекций. |

## Применение в Яндексе
- **Кэширование и индексация**: Хранение миллионов узлов графов, поисковых индексов и кэш-сущностей в памяти сервисов.
- **Обработка больших данных**: Потоковая обработка логов в бэкенд-воркерах без риска падения по `OOM (Out Of Memory)`.
