# 📖 Лекция 02: Множества (Sets)

## Что это и зачем в контесте

`set` — это хеш-таблица **без значений**. Только ключи. Проверка «есть ли элемент» — O(1).

**Мнемоника:** `set` = «СЕТка» — ловит дубликаты, как сетка ловит рыбу. Если что-то уже в сетке — это дубликат.

В Яндексе: проверка уникальности email, дедупликация событий в ленте, пересечение массивов.

## Базовый код

```python
s = set()
s.add(1)          # вставка O(1)
3 in s            # проверка O(1) → False
s.remove(4)       # удаление (ошибка, если нет)
s.discard(10)     # безопасное удаление (нет ошибки)
```

## Операции (визуально)

```python
a = {1, 2, 3}
b = {2, 3, 4}

a & b   # пересечение: {2, 3}  → "что общего"
a | b   # объединение: {1, 2, 3, 4} → "всё вместе"
a - b   # разность: {1} → "только в a"
a ^ b   # симметричная разность: {1, 4} → "только в одном"
```

**Мнемоника для операций:**
- `&` — «и» (пересечение) → общие друзья
- `|` — «или» (объединение) → все друзья
- `-` — «минус» → кто ушёл
- `^` — «исключающее или» → кто в одной группе, но не в другой

## Сложность

| Операция | Время | Память |
|----------|-------|--------|
| Добавить (`add`) | O(1) | O(1) |
| Проверить (`in`) | O(1) | — |
| Удалить (`remove`) | O(1) | — |
| Перебор | O(n) | — |

## Когда использовать

- **Дедупликация:** `len(set(arr)) == len(arr)`
- **Пересечение массивов:** `set(a) & set(b)`
- **Проверка уникальности:** `len(set(nums)) == len(nums)`
- **Удаление дубликатов с сохранением порядка:** `list(dict.fromkeys(arr))`

## Вопросы на собеседовании в Яндексе

1. «Пересечение массивов» → `set(a) & set(b)`
2. `set` vs `dict` → `set` — только ключи, `dict` — ключ + значение
3. «Убрать дубликаты с порядком» → `dict.fromkeys(arr)`
4. «Можно ли изменить элемент в set?» → Нет, элементы должны быть `hashable` (неизменяемые)

## Правило ключей (повтор из лекции 01)

Ключ в `set` должен быть хешируемым (`hashable`). Можно: `int`, `str`, `tuple`. Нельзя: `list`, `dict`, `set`.

```python
# ❌ list как элемент — ошибка
s = set()
s.add([1, 2])     # TypeError: unhashable type: 'list'

# ✅ tuple как элемент
s.add((1, 2))
