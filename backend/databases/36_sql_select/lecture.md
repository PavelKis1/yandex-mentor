# Лекция: 36 — Базовый SQL: SELECT, WHERE, ORDER BY, LIMIT

## Обзор темы
Запросы на выборку данных (`SELECT`) — фундамент взаимодействия с реляционными базами данных (PostgreSQL, MySQL, SQLite). Уверенное владение фильтрацией, сортировкой и пагинацией необходимо каждому бэкенд-разработчику.

---

## Подробный теоретический минимум

### 1. Порядок выполнения SQL-запроса (Logical Query Processing)
Важно понимать, в каком порядке СУБД обрабатывает части запроса:
1. `FROM` и `JOIN` (формирование исходного набора строк)
2. `WHERE` (фильтрация строк)
3. `GROUP BY` (группировка)
4. `HAVING` (фильтрация групп)
5. `SELECT` (вычисление выражений и выборка колонок)
6. `DISTINCT` (удаление дубликатов)
7. `ORDER BY` (сортировка результатов)
8. `LIMIT` / `OFFSET` (ограничение выдачи)

### 2. Фильтрация и сортировка
- **`WHERE`**: фильтрация данных по условиям (`=`, `!=`, `IN`, `LIKE`, `IS NULL`, `BETWEEN`).
- **`ORDER BY`**: сортировка результатов по возрастанию (`ASC`) или убыванию (`DESC`).
- **`LIMIT` и `OFFSET`**: ограничение количества возвращаемых строк и смещение (пагинация). *Примечание: большой `OFFSET` неэффективен, так как СУБД все равно читает и пропускает строки.*

---

## Производственный пример кода

Пример SQL-запроса для выборки активных пользователей с пагинацией:

```sql
-- Выборка активных пользователей с сортировкой по дате регистрации
SELECT id, username, email, created_at
FROM users
WHERE status = 'active' AND created_at >= '2026-01-01'
ORDER BY created_at DESC
LIMIT 20 OFFSET 0;
```

## Анализ сложности (Big O)

| Операция | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **Seq Scan (без индекса)** | $O(N)$ | $O(1)$ | Полный перебор таблиц при отсутствии подходящего индекса. |
| **Index Scan** | $O(\log N + K)$ | $O(K)$ | $K$ — количество строк, удовлетворяющих условию. |
| **ORDER BY (без индекса)** | $O(N \log N)$ | $O(N)$ | Сортировка результатов в памяти (External Merge Sort при нехватке work_mem). |
