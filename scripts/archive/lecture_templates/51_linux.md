# 📖 Лекция 51: Linux (Базовое администрирование)

## 📝 О чем это
Базовые навыки работы в командной строке Linux, необходимые для управления серверами и деплоя приложений.

## 💡 Основные концепции
*   **Файловая система**: Иерархия каталогов, права доступа (`chmod`, `chown`).
*   **Процессы**: Мониторинг и управление (`ps`, `top`, `kill`).
*   **Сеть**: Проверка соединений (`ping`, `netstat`, `ss`).
*   **Утилиты**: Поиск, обработка текста (`grep`, `awk`, `sed`).

## 💻 Базовый код
```bash
# Найти все файлы .log
find . -name "*.log"

# Посмотреть процессы
ps aux | grep python
```

## 🚀 Сложность
Зависит от задачи, основные команды выполняются за $O(1)$ - $O(N)$.

# 📖 Лекция: 51 — Linux (Основы)

## Обзор темы
Понимание основ Linux критически важно для бэкенд-разработки и администрирования сервисов.

## Подробный теоретический минимум
- **Файловая система**: Структура каталогов, права доступа (`chmod`, `chown`).
- **Командная строка**: `grep`, `awk`, `sed`, `top`, `htop`, `ps`.
- **Управление процессами**: `kill`, `nohup`, `systemctl`.
