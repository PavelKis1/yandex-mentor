# 📖 Лекция: 43 — Redis

## Обзор темы
Redis — это NoSQL In-Memory хранилище данных типа "ключ-значение".

## Подробный теоретический минимум
- **Типы данных**: String, Hash, List, Set, Sorted Set.
- **Особенности**: Очень высокая скорость (операции в RAM), персистентность (RDB/AOF), Pub/Sub.

## Производственный пример кода
```python
import redis
r = redis.Redis(host='localhost', port=6379, db=0)
r.set('foo', 'bar')
print(r.get('foo'))
```

## Применение в Яндексе
- Кэширование запросов, сессии пользователей, счетчики.
