# 📖 Лекция: 34 — Датаклассы (Dataclasses)

## Обзор темы
`dataclasses` (Python 3.7+) — способ быстрого создания классов, предназначенных в основном для хранения данных, с автоматической генерацией `__init__`, `__repr__`, `__eq__`.

## Подробный теоретический минимум
- Декоратор `@dataclass`.
- Аннотации типов.
- Неизменяемость (`frozen=True`).

## Производственный пример кода
```python
from dataclasses import dataclass

@dataclass(frozen=True)
class User:
    id: int
    name: str

u = User(1, "Pavel")
```

## Анализ сложности
- Снижает бойлерплейт-код, производительность сопоставима с обычными классами.

## Применение в Яндексе
- Определение структур данных для API, DTO (Data Transfer Objects), конфигураций.
