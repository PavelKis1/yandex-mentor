# 📖 Лекция 62: Search (Поисковая система)

## 📝 О чем это
Проектирование поискового движка.

## 💡 Основные концепции
*   **Индексация**: Инвертированный индекс.
*   **Ранжирование**: TF-IDF, PageRank.

## 💻 Базовый код
```python
# Упрощенный инвертированный индекс
index = {'python': [doc1, doc2], 'search': [doc1]}
```

## 🚀 Сложность
$O(1)$ поиск по индексу.
