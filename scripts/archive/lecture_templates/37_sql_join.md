# 📖 Лекция: 37 — SQL JOIN

## Обзор темы
Объединение таблиц по общему ключу.

## Подробный теоретический минимум
- Типы JOIN: `INNER`, `LEFT`, `RIGHT`, `FULL OUTER`.
- Работа с null-значениями.

## Производственный пример кода
```sql
SELECT u.name, o.id FROM users u JOIN orders o ON u.id = o.user_id;
```

## Анализ сложности
- Оптимизация JOIN (Hash Join, Merge Join) критична для производительности.

## Применение в Яндексе
- Связывание пользователей с их заказами, историей поисковых запросов и т.д.
