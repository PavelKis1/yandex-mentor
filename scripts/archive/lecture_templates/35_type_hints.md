# 📖 Лекция: 35 — Подсказки типов (Type Hints)

## Обзор темы
Type Hinting делает код более читаемым, предсказуемым и упрощает статическую проверку ошибок (через `mypy`).

## Подробный теоретический минимум
- Типы: `int`, `str`, `List`, `Dict`, `Optional`, `Union`, `Callable`.
- `typing` модуль.

## Производственный пример кода
```python
from typing import List, Optional

def get_user(id: int) -> Optional[str]:
    return "Pavel" if id == 1 else None
```

## Анализ сложности
- $O(0)$ в runtime (типы игнорируются интерпретатором, используются только инструментами статического анализа).

## Применение в Яндексе
- Крупные кодовые базы, разработка сложных микросервисов, улучшение качества кода.
