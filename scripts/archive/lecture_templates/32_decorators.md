# 📖 Лекция: 32 — Декораторы (Decorators)

## Обзор темы
Декораторы — это мощный инструмент для изменения поведения функций или классов без изменения их исходного кода (метапрограммирование).

## Подробный теоретический минимум
- **Функции первого класса**: Функции как аргументы и возвращаемые значения.
- **Замыкания (Closures)**: Запоминание области видимости.
- **`functools.wraps`**: Сохранение метаданных оригинальной функции.

## Производственный пример кода
```python
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time: {time.time() - start}")
        return result
    return wrapper

@timer
def heavy_task():
    pass
```

## Анализ сложности
- Добавление декоратора — $O(1)$, но выполнение обертки добавляет небольшой overhead на каждый вызов.

## Применение в Яндексе
- Логирование, аутентификация, кэширование, валидация входных данных в API.
