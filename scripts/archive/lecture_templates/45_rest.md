# 📖 Лекция: 45 — REST API

## Обзор темы
REST — архитектурный стиль взаимодействия компонентов распределенной системы.

## Подробный теоретический минимум
- **Принципы**: Клиент-сервер, отсутствие состояния (stateless), кэшируемость, единый интерфейс.
- **Ресурсы**: Использование URI для идентификации ресурсов.
