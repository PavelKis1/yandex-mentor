# 📖 Лекция: 40 — Индексы в SQL (Indexes)

## Обзор темы
Индексы — механизм ускорения поиска данных в таблицах.

## Подробный теоретический минимум
- B-Tree, Hash индексы.
- Кластерные и некластерные индексы.
- Стоимость использования: ускорение чтения, замедление записи.

## Производственный пример кода
```sql
CREATE INDEX idx_users_email ON users(email);
```

## Анализ сложности
- Поиск: $O(\log N)$. Вставка/обновление: $O(\log N)$.

## Применение в Яндексе
- Ускорение работы БД для обеспечения низкого latency в высоконагруженных проектах.
