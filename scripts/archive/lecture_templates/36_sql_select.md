# 📖 Лекция: 36 — SQL SELECT

## Обзор темы
Основа работы с реляционными базами данных — получение данных.

## Подробный теоретический минимум
- Структура запроса: `SELECT`, `FROM`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, `LIMIT`.
- Фильтрация и проекция.

## Производственный пример кода
```sql
SELECT name, age FROM users WHERE age > 18 ORDER BY name DESC LIMIT 10;
```

## Анализ сложности
- Зависит от индексов: от $O(1)$ до $O(N)$.

## Применение в Яндексе
- Получение данных из БД для всех сервисов (Маркет, Такси, Поиск).
