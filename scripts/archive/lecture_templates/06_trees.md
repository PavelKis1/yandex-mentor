# 📖 Лекция 06: Деревья (Trees)

## 📝 О чем это
Дерево — это иерархическая структура данных, состоящая из узлов. Один узел является корневым, а остальные образуют поддеревья. Основной тип, используемый в задачах — Бинарное дерево поиска (BST).

## 💡 Основные концепции
*   **Бинарное дерево (Binary Tree)**: Каждый узел имеет не более двух потомков.
*   **Бинарное дерево поиска (BST)**: Для любого узла все значения в левом поддереве меньше, а в правом — больше. Это позволяет искать элементы за O(log n).
*   **Обходы (Traversals)**:
    *   `Pre-order` (корень -> лево -> право)
    *   `In-order` (лево -> корень -> право)
    *   `Post-order` (лево -> право -> корень)

## 🛠 Популярные операции
*   `search(value)`: Поиск в BST — O(log n) (в среднем).
*   `insert(value)`: Вставка с сохранением свойств BST — O(log n).

## 💻 Базовый код
```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

## 🚀 Сложность
*   Поиск/Вставка: O(log n) в среднем, O(n) в худшем случае (если дерево выродилось в список).
