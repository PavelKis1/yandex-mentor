# 📖 Лекция 13: Динамическое программирование 1D (DP 1D)

## 📝 О чем это
Динамическое программирование (ДП) — метод решения задач путем разбиения их на более простые подзадачи. Результаты подзадач сохраняются (кэшируются) для исключения повторных вычислений.

## 💡 Основные концепции
*   **Оптимальная подструктура**: Оптимальное решение задачи содержит оптимальные решения её подзадач.
*   **Перекрывающиеся подзадачи**: Одна и та же подзадача решается многократно.
*   **Мемоизация (Top-Down)**: Рекурсия + кэширование.
*   **Табуляция (Bottom-Up)**: Итеративное заполнение массива.

## 💻 Базовый код
```python
# Числа Фибоначчи через ДП (Bottom-Up)
def fib(n):
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```
