# 📖 Лекция: 48 — Docker

## Обзор темы
Docker — платформа для контейнеризации приложений, позволяющая упаковать приложение и все его зависимости в контейнер.

## Подробный теоретический минимум
- **Dockerfile**: Инструкции по сборке образа.
- **Image**: "Снимок" файловой системы.
- **Container**: Запущенный экземпляр образа.
