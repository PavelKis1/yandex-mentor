# 📖 Лекция: 46 — FastAPI

## Обзор темы
FastAPI — современный, быстрый (high-performance) фреймворк для создания API на Python 3.6+, основанный на стандартных подсказках типов Python.

## Подробный теоретический минимум
- **Особенности**: Автоматическая документация (Swagger), асинхронность (async/await), валидация данных (Pydantic).
