# 📖 Лекция 20: Union-Find (DSU)

## 📝 О чем это
Структура данных для отслеживания множеств, разделенных на непересекающиеся подмножества.

## 🛠 Популярные методы
- `find(x)`: поиск представителя.
- `union(x, y)`: объединение множеств.
