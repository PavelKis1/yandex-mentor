# 📖 Лекция 05: Связные списки (Linked Lists)

## 📝 О чем это
Связный список — это линейная структура данных, где каждый элемент (узел) содержит значение и ссылку на следующий элемент. В отличие от массивов, элементы списка не хранятся в непрерывной области памяти. Это дает преимущество при вставке и удалении элементов.

## 💡 Основные концепции
*   **Узел (Node)**: Базовый элемент, состоящий из данных (`data`) и указателя (`next`).
*   **Типы списков**:
    *   **Односвязный**: Каждый узел указывает только на следующий.
    *   **Двусвязный**: Узлы имеют ссылки и на следующий, и на предыдущий элемент (позволяет двигаться в обе стороны).
    *   **Кольцевой**: Последний узел указывает на первый.

## 🛠 Популярные методы (для Python-подобной реализации)
*   `insert_at_beginning(data)`: Добавление в начало — O(1).
*   `insert_at_end(data)`: Добавление в конец — O(n) (если нет ссылки на хвост).
*   `delete_node(key)`: Удаление узла по значению — O(n).
*   `search(key)`: Поиск узла — O(n).

## 💻 Базовый код
```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None
```

## 🚀 Сложность
| Операция | Сложность |
|---|---|
| Поиск | O(n) |
| Вставка в начало | O(1) |
| Вставка в конец | O(n) или O(1) с хвостом |
