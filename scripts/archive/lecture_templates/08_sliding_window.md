# 📖 Лекция 08: Скользящее окно (Sliding Window)

## 📝 О чем это
Метод скользящего окна используется для решения задач на массивах или строках, где нужно найти подмассив или подстроку, удовлетворяющую заданному условию. Он позволяет избежать вложенных циклов.

## 💡 Основные концепции
*   Поддерживаем два указателя (`left`, `right`), которые ограничивают текущее "окно".
*   Двигаем `right` для расширения окна, двигаем `left` для сужения, когда условие нарушается.

## 🛠 Применение
*   Поиск максимальной суммы подмассива фиксированной длины.
*   Поиск самой длинной подстроки без повторяющихся символов.

## 💻 Базовый код
```python
def sliding_window(arr, k):
    max_sum = current_sum = sum(arr[:k])
    for i in range(len(arr) - k):
        current_sum = current_sum - arr[i] + arr[i+k]
        max_sum = max(max_sum, current_sum)
    return max_sum
```

## 🚀 Сложность
*   Обычно O(n), так как каждый элемент посещается не более двух раз.
