# 📖 Лекция: 31 — Оптимизация Python (Optimization)

## Обзор темы
Оптимизация кода в Python — это искусство баланса между читаемостью и производительностью. Важно понимать, когда преждевременная оптимизация вредит, а когда она критически необходима.

## Подробный теоретический минимум
- **Профилирование**: Использование `cProfile` и `line_profiler` для поиска узких мест (bottlenecks).
- **Структуры данных**: Правильный выбор между `list`, `set`, `dict`, `deque`.
- **Встроенные функции**: Использование map, filter, list comprehensions (часто быстрее циклов).
- **Локальные vs Глобальные переменные**: Обращение к локальным переменным быстрее.

## Производственный пример кода
```python
# Оптимизация поиска в списке через set
items = [1, 2, 3, 4, 5] * 1000
# Медленно: O(n)
if 5 in items: pass
# Быстро: O(1)
items_set = set(items)
if 5 in items_set: pass
```

## Анализ сложности
- Оптимизация алгоритмов часто снижает сложность с $O(N^2)$ до $O(N)$ или $O(N \log N)$.

## Применение в Яндексе
- Оптимизация критических путей в сервисах, работающих под высокой нагрузкой (поиск, реклама).
