# 📖 Лекция: 39 — SQL Window Functions

## Обзор темы
Функции, работающие с окном строк, не сворачивая их.

## Подробный теоретический минимум
- `OVER`, `PARTITION BY`, `ORDER BY` внутри окна.
- `ROW_NUMBER`, `RANK`, `LEAD`, `LAG`.

## Производственный пример кода
```sql
SELECT name, salary, AVG(salary) OVER(PARTITION BY department) FROM employees;
```

## Анализ сложности
- Обычно $O(N \log N)$ из-за сортировки внутри окна.

## Применение в Яндексе
- Расчет скользящих средних, ранжирование, анализ временных рядов.
