# 📖 Лекция: 41 — SQL EXPLAIN (Оптимизация запросов)

## Обзор темы
`EXPLAIN` — ключевой инструмент для анализа планов выполнения SQL-запросов. Без него невозможно понять, почему запрос работает медленно.

## Подробный теоретический минимум
- **Что делает EXPLAIN**: Показывает, как БД собирается выполнять запрос (какие индексы использует, какой тип join, сколько строк сканирует).
- **Ключевые колонки**: `type`, `key`, `rows`, `Extra`.
- **Типы JOIN**: `ALL` (full table scan - плохо), `index`, `range`, `ref`, `eq_ref`, `const`.

## Производственный пример кода
```sql
-- Анализ медленного запроса
EXPLAIN SELECT * FROM users WHERE email = 'test@example.com';
```

## Анализ сложности
- Анализ `EXPLAIN` позволяет снизить сложность запроса с $O(N)$ до $O(\log N)$ за счет использования индексов.

## Применение в Яндексе
- Оптимизация запросов к БД в высоконагруженных сервисах (Такси, Маркет).
