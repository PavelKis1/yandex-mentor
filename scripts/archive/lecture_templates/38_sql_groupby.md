# 📖 Лекция: 38 — SQL GROUP BY

## Обзор темы
Агрегация данных в группах.

## Подробный теоретический минимум
- Агрегатные функции: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.
- Использование `HAVING` для фильтрации групп.

## Производственный пример кода
```sql
SELECT status, COUNT(*) FROM orders GROUP BY status;
```

## Анализ сложности
- $O(N \log N)$ или $O(N)$ при хэшировании.

## Применение в Яндексе
- Статистика по заказам, анализ логов, отчетность.
