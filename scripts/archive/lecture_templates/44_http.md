# 📖 Лекция: 44 — HTTP

## Обзор темы
HTTP — протокол передачи гипертекста, основа современного веб-интернета.

## Подробный теоретический минимум
- **Методы**: GET, POST, PUT, DELETE, PATCH.
- **Статус-коды**: 2xx (успех), 3xx (редирект), 4xx (ошибка клиента), 5xx (ошибка сервера).
- **Заголовки**: Content-Type, Authorization, Cookie.
