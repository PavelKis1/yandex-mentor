# 📖 Лекция 26: Collections (Специализированные контейнеры данных)

## 📝 О чем это
Модуль `collections` в стандартной библиотеке Python предоставляет специализированные контейнеры данных, которые расширяют возможности встроенных структур (`dict`, `list`, `set`, `tuple`). Знание этих структур — базовый навык для успешного прохождения секции алгоритмов и системного дизайна на собеседованиях в Яндекс.

## 💡 Основные концепции
*   **Counter**: Подкласс словаря для подсчета хэшируемых объектов. Поддерживает арифметические операции над мультимножествами.
*   **defaultdict**: Словарь, который автоматически создает значение по умолчанию для отсутствующих ключей.
*   **deque**: Двусторонняя очередь с эффективными операциями добавления/удаления с обоих концов ($O(1)$).
*   **namedtuple**: Фабрика для создания подклассов кортежей с именованными полями.

## 🛠 Популярные методы
*   `Counter.most_common(n)`: Получение топ-N элементов.
*   `deque.appendleft()`, `deque.popleft()`: Быстрые операции с начала очереди.

## 💻 Базовый код
```python
from collections import Counter, defaultdict, deque

# Counter
c = Counter("abracadabra")
print(c.most_common(2)) # [('a', 5), ('b', 2)]

# defaultdict
d = defaultdict(int)
d['a'] += 1 # Не вызывает KeyError

# deque
q = deque([1, 2, 3])
q.appendleft(0)
```

## 🚀 Сложность
| Операция | Сложность |
|---|---|
| Counter.most_common(k) | $O(N + K \log N)$ |
| defaultdict[key] | $O(1)$ |
| deque.appendleft() | $O(1)$ |
