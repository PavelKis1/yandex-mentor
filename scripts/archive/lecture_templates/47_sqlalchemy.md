# 📖 Лекция: 47 — SQLAlchemy (ORM)

## Обзор темы
SQLAlchemy — библиотека Python для работы с реляционными базами данных, предоставляющая ORM (Object Relational Mapper).

## Подробный теоретический минимум
- **ORM**: Позволяет работать с БД как с обычными Python-объектами.
- **Session**: Управление транзакциями.
