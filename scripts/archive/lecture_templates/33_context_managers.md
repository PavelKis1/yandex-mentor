# 📖 Лекция: 33 — Контекстные менеджеры (Context Managers)

## Обзор темы
Контекстные менеджеры обеспечивают корректное управление ресурсами (открытие/закрытие файлов, соединений с БД, блокировки), гарантируя их освобождение даже при ошибках.

## Подробный теоретический минимум
- Оператор `with`.
- Интерфейс: `__enter__` и `__exit__`.
- Модуль `contextlib` (декоратор `@contextmanager`).

## Производственный пример кода
```python
class ManagedResource:
    def __enter__(self):
        print("Resource acquired")
        return self
    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Resource released")

with ManagedResource():
    print("Working")
```

## Анализ сложности
- $O(1)$ на управление ресурсом.

## Применение в Яндексе
- Работа с файлами, сетевыми соединениями, транзакциями в БД.
