Клиент жалуется: POST /orders иногда возвращает 500. Как расследовать?

**Пример:** `Логи/трейсы, воспроизведение, метрики`

## Задание 2: SQL на собесе
Напишите запрос: 3 самых дорогих заказа каждого клиента (оконные функции).

**Пример:** `ROW_NUMBER() OVER (PARTITION BY client_id ORDER BY amount DESC) rn; rn <= 3`

💡 **Подсказка:** PARTITION BY + фильтр по rn.
