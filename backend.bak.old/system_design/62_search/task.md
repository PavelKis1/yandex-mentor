# Задания: Search

## Задание 1: Индексирование
Как устроен полнотекстовый поиск по 10M документов? Опишите pipeline.

**Пример:** `crawler → нормализация → inverted index`

💡 **Подсказка:** Inverted index: слово → список документов.

## Задание 2: Ранжирование
Почему простое количество совпадений недостаточно? Что добавить?

**Пример:** `TF-IDF, частота, позиция, релевантность`

💡 **Подсказка:** Сначала фильтр, потом ранжирование.

## Задание 3: Поддержка опечаток
Пользователь печатает 'быстра' вместо 'быстрая'. Как исправить?

**Пример:** `Автополнение, редакционное расстояние / n-граммы`

💡 **Подсказка:** Fuzzy match по индексу.
