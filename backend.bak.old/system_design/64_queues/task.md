# Задания: Queues

## Задание 1: Работа очереди
Producer отправляет задачи, worker обрабатывает. Какие гарантии даёт очередь (at-most-once, at-least-once)?

**Пример:** `at-least-once: повторная доставка после краха`

💡 **Подсказка:** Идемпотентность обработчиков.

## Задание 2: Задержка задач
Письмо должно отправиться через 30 минут после регистрации. Как реализовать?

**Пример:** `RabbitMQ delayed exchange / Redis ZSET по времени`

💡 **Подсказка:** Отложенные задачи в планировщике.

## Задание 3: Dead letter queue
Задача падает всегда (битый JSON). Она блокирует очередь. Как её отложить?

**Пример:** `Retry с счётчиком → DLQ после N попыток`

💡 **Подсказка:** DLQ + алертинг.
