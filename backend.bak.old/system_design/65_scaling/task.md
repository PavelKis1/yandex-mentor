# Задания: Scaling

## Задание 1: Горизонтальное масштабирование
API тормозит при 1000 RPS. Что делает горизонтальное масштабирование и какие подводные камни?

**Пример:** `Несколько реплик за LB; состояние сессий вне процесса`

💡 **Подсказка:** Stateless API + общий кэш/БД.

## Задание 2: База: шардирование
Таблица users стала 500M строк. Как разделить по шардам?

**Пример:** `Партиционирование/шардирование по user_id (hash/range)`

💡 **Подсказка:** Ключ шарда = хеш, чтобы читать с одного шарда.

## Задание 3: Метрики нагрузки
Назовите 3 метрики, по которым вы решите, что пора масштабироваться.

**Пример:** `CPU/loadavg, p99 latency, error rate`

💡 **Подсказка:** SLO/SLI: 99.9% < 500 мс.
