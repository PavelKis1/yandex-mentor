# Задания: Logging

## Задание 1: Конфигурация
Настройте Python logging: вывод в stdout + файл app.log, формат со временем и уровнем.

**Пример:** `logging.basicConfig(level=INFO, handlers=[...])`

💡 **Подсказка:** FileHandler + StreamHandler, формат.

## Задание 2: Уровни
Когда использовать debug/info/warning/error? Назовите по одному примеру.

**Пример:** `debug: подробности; info: значимые события; error: сбой`

💡 **Подсказка:** Уровни по важности.

## Задание 3: Структурированные логи
Почему JSON-логи лучше текстовых для продакшена и как их сделать?

**Пример:** `json.dumps(record) в кастомном Formatter`

💡 **Подсказка:** Парсинг/поиск/агрегация.
