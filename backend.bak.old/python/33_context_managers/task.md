# Задания: Context Managers

## Задание 1: Файл-менеджер
Напишите контекстный менеджер open_file(path, mode), который гарантирует закрытие файла, и используйте его с 'with'.

**Пример:** `with open_file('tmp.txt','w') as f: f.write('hi') — файл закрыт после`

💡 **Подсказка:** class с __enter__/__exit__ или @contextmanager с yield.

## Задание 2: Таймер как менеджер
Напишите контекстный менеджер timed_block. В 'with' блоке он измеряет время выполнения и печатает его.

**Пример:** `with timed_block(): ...  → 'block took 0.15 s'`

💡 **Подсказка:** @contextmanager: время до yield и после.

## Задание 3: Подавление исключений
Напишите контекстный менеджер suppress(Exc), который подавляет указанное исключение внутри блока и продолжает выполнение.

**Пример:** `with suppress(ValueError): int('abc') — ошибки нет`

💡 **Подсказка:** __exit__ возвращает True при совпадении исключения.
