# Лекция: 33 — Контекстные менеджеры (Context Managers)

## Обзор темы
Контекстные менеджеры в паре с оператором `with` обеспечивают идиоматичное и безопасное управление ресурсами (файлы, сетевые соединения, блокировки потоков, транзакции БД), гарантируя их освобождение даже в случае возникновения исключений.

---

## Подробный теоретический минимум

### 1. Протокол контекстного менеджера (`__enter__` и `__exit__`)
Чтобы объект поддерживал оператор `with`, он должен реализовать два метода:
- **`__enter__(self)`**: выполняется перед входом в блок `with`. Возвращаемое значение привязывается к переменной после ключевого слова `as`.
- **`__exit__(self, exc_type, exc_val, exc_tb)`**: выполняется при выходе из блока. Если внутри блока произошло исключение, его тип, значение и traceback передаются в аргументы. Возврат `True` подавляет исключение.

### 2. Модуль `contextlib` и `@contextmanager`
Создание классов с методами `__enter__`/`__exit__` бывает избыточным. Декоратор `@contextmanager` превращает функцию-генератор в контекстный менеджер:
- Код до `yield` выполняет роль `__enter__`.
- Значение после `yield` передается в `as`.
- Код после `yield` (в блоке `finally`) выполняет роль `__exit__`.

---

## Производственный пример кода

Реализация безопасного таймера измерения времени выполнения блока кода в виде контекстного менеджера:

```python
from contextlib import contextmanager
import time
import logging

@contextmanager
def execution_timer(operation_name: str):
    start = time.perf_counter()
    try:
        yield
    except Exception as e:
        print(f"Operation '{operation_name}' failed with error: {e}")
        raise
    finally:
        duration = time.perf_counter() - start
        print(f"Operation '{operation_name}' completed in {duration:.4f}s")

if __name__ == "__main__":
    with execution_timer("Heavy DB Migration"):
        time.sleep(0.05)  # Имитация работы
    print("Контекстный менеджер успешно проверен!")
```

## Анализ сложности (Big O)

| Операция | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **Вход и выход из контекста** | $O(1)$ | $O(1)$ | Минимальные накладные расходы на вызов методов протокола. |

## Применение в Яндексе
- **Транзакции баз данных**: Автоматический `COMMIT` при успешном завершении или `ROLLBACK` при ошибке.
- **Сетевые клиенты**: Гарантированное закрытие HTTP-соединений (`httpx`, `aiohttp`) и пулов соединений.
- **Многопоточность**: Управление мьютексами и блокировками (`threading.Lock`).
