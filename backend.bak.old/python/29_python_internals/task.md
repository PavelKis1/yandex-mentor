# Задания: Python Internals

## Задание 1: Иммутабельность int/str
Объясните и продемонстрируйте кодом: почему a = 5; b = a; a = 6 — а остаётся 5? Напишите функцию, которая принимает список и число, меняет список in-place и возвращает новое число.

**Пример:** `f([1,2,3], 4) → [1,2,3,4], вернула 4`

💡 **Подсказка:** Целые и строки иммутабельны; списки — мутабельны, передаются по ссылке.

## Задание 2: Замыкания
Напишите счётчик-замыкание: функция, которая при каждом вызове возвращает 1,2,3,... — используя nonlocal.

**Пример:** `increment() три раза → 1, 2, 3`

💡 **Подсказка:** Внутренняя функция + nonlocal count.

## Задание 3: Генераторы: ленивость
Напишите генератор, который выдаёт первые n простых чисел, не вычисляя все заранее. Покажите, что значения считаются лениво (через yield).

**Пример:** `first_n_primes(3) → [2,3,5]`

💡 **Подсказка:** Решето Эратосфена как генератор с yield.
