# Задания: Itertools

## Задание 1: Комбинации
Дан массив nums и число k. Верните все комбинации по k элементов (без itertools.combinations).

**Пример:** `nums=[1,2,3,4], k=2 → [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`

💡 **Подсказка:** Рекурсия + бэктрекинг, либо itertools.combinations для эталона.

## Задание 2: Произведение списков
Дан список списков. Верните всевозможные произведения их элементов через itertools.product, но без повторений одинаковых кортежей.

**Пример:** `[1,2] x [3,4] → [(1,3),(1,4),(2,3),(2,4)]`

💡 **Подсказка:** itertools.product(*lists) + set для дедупликации.

## Задание 3: Бесконечный счётчик
Создайте кастомный итератор, который бесконечно выдаёт числа 0,1,2,...,n-1,0,1,... (реализуйте через cycle+count или генератор).

**Пример:** `первые 7 значений: 0,1,2,3,0,1,2`

💡 **Подсказка:** Напиши генератор с while True и % n; для эталона — itertools.cycle(range(n)).
