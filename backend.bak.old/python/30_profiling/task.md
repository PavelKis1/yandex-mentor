# Задания: Profiling

## Задание 1: Замер времени
Дан список из 10^6 чисел. Сравните время создания списка квадратов через list comprehension против for-цикла с append. Верните соотношение.

**Пример:** `comprehension обычно в 1.5–2× быстрее`

💡 **Подсказка:** time.perf_counter() вокруг каждой версии, повторите 3 раза, возьмите минимум.

## Задание 2: Найти узкое место
Дана функция с вложенным циклом: find_duplicates(nums). Профилируйте её через cProfile и найдите функцию-узкое место.

**Пример:** `cProfile: большая часть времени — в inner loop`

💡 **Подсказка:** Пиши в файл: python -m cProfile -o out.prof script.py; смотри stats.

## Задание 3: Память
Измерьте потребление памяти списком из 10^6 целых через tracemalloc. Верните примерный размер в МБ.

**Пример:** `~8 МБ (64-бит Python)`

💡 **Подсказка:** tracemalloc.start() → выполни → tracemalloc.get_traced_memory().
