# Задания: Optimization

## Задание 1: Два указателя
Дан отсортированный массив. Найдите пару с суммой, равной target, за O(n) через два указателя.

**Пример:** `[1,2,3,4,6], target=8 → (2,6)`

💡 **Подсказка:** left=0, right=n-1; двигай left вправо, right влево.

## Задание 2: Хеш вместо цикла
Дан массив. Найдите первый дубликат за O(n) с O(n) памяти (через set) и верните его индекс.

**Пример:** `[2,1,3,2,4] → индекс 3`

💡 **Подсказка:** Классический «уже видели» за O(1) на проверку.

## Задание 3: Пропустить половину
Дан большой отсортированный массив и target. Найдите индекс target за O(log n) через бинарный поиск (без bisect).

**Пример:** `search([1,3,5,7,9], 5) → 2`

💡 **Подсказка:** half = (l + r) // 2, сужай диапазон в два раза.
