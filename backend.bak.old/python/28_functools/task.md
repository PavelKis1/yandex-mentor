# Задания: Functools

## Задание 1: Частичное применение
Дан список цен и скидка. Через functools.partial сделайте функцию discount(price), возвращающую цену со скидкой, и примените её ко всем ценам.

**Пример:** `prices=[100,200,300], скидка 10% → [90,180,270]`

💡 **Подсказка:** partial скидывает фиксированный аргумент: discount = partial(apply_discount, rate=0.1).

## Задание 2: Мемоизация
Реализуйте рекурсивную функцию чисел Фибоначчи с кэшированием через functools.lru_cache. Сравните количество вызовов с наивной версией.

**Пример:** `fib(30) → 832040, вызовов ≤ 2*n`

💡 **Подсказка:** @lru_cache(maxsize=None) на внутренней функции.

## Задание 3: Редукция
Дан список чисел. Через functools.reduce найдите максимальный элемент, НЕ используя max().

**Пример:** `[3,7,2,9,5] → 9`

💡 **Подсказка:** reduce(lambda a,b: a if a>b else b, nums) или functools.reduce(max, nums).
