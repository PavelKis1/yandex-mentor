# Задания: Decorators

## Задание 1: Таймер-декоратор
Напишите декоратор @timed, который печатает время выполнения функции в миллисекундах и возвращает результат неизменным.

**Пример:** `печать 'slow took 123 ms', вернул результат`

💡 **Подсказка:** functools.wraps(f); time.perf_counter() до и после.

## Задание 2: Логирование вызовов
Напишите декоратор @logged, который логирует имя функции, аргументы и результат каждого вызова в список LOG.

**Пример:** `LOG = []; @logged f(2) → LOG = [('f', (2,), result)]`

💡 **Подсказка:** Декоратор с *args, **kwargs и wrapped.__name__.

## Задание 3: Повтор с задержкой
Напишите декоратор @retry(times=3, delay=0.1), который повторяет функцию при исключении и пробрасывает ошибку после times попыток.

**Пример:** `f бросает ValueError 2 раза подряд, times=3 → 3-я попытка успешна`

💡 **Подсказка:** for i in range(times): try: return f(*a,**kw) except: time.sleep(delay).
