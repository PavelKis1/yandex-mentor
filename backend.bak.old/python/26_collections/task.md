# Задания: Collections

## Задание 1: Топ K частых элементов
Дан массив nums и число k. Верните k наиболее часто встречающихся элементов. Порядок не важен.

**Пример:** `nums=[1,1,1,2,2,3], k=2 → [1,2]`

💡 **Подсказка:** Используй collections.Counter + heapq.nlargest (O(n log k)).

## Задание 2: Группа анаграмм
Дан массив строк strs. Сгруппируйте анаграммы вместе. Верните список групп.

**Пример:** `strs=['eat','tea','tan','ate','nat','bat'] → [['bat'],['tan','nat'],['eat','tea','ate']]`

💡 **Подсказка:** Ключ группы — отсортированная строка или tuple(Counter).

## Задание 3: Палиндром с deque
Проверьте, является ли строка палиндромом, с учётом только букв и цифр (игнорируя регистр). Реализуйте через collections.deque.

**Пример:** `s='A man, a plan, a canal: Panama' → True`

💡 **Подсказка:** Двусторонний deque: pop слева и справа за O(1), сравнивай буквы.
