# Задания: Security

## Задание 1: Инъекции
Пользователь вводит в поиск: ' OR 1=1; --. Чем опасен такой ввод и как защититься?

**Пример:** `SQL-инъекция: параметризуй запросы (не конкатенация)`

💡 **Подсказка:** SQLAlchemy .execute с параметрами.

## Задание 2: Пароли
Как хранить пароли пользователей безопасно? Почему нельзя sha256 напрямую?

**Пример:** `bcrypt/argon2 с солью`

💡 **Подсказка:** хэширование + соль + медленная функция.

## Задание 3: Заголовки
Перечислите 3 security-заголовка для ответа API и зачем они.

**Пример:** `CSP, X-Content-Type-Options, Strict-Transport-Security`

💡 **Подсказка:** Защита XSS/sniffing/понижения.
