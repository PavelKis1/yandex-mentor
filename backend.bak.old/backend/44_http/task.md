# Задания: Http

## Задание 1: Коды ответа
Для каждой ситуации назовите корректный HTTP-код: 'не найдено', 'нет прав', 'создано', 'валидация не прошла'.

**Пример:** `404, 403, 201, 422`

💡 **Подсказка:** Коды: клиентские 4xx, серверные 5xx.

## Задание 2: Заголовки кэша
Ответ с большим статическим файлом должен кэшироваться на день. Какие заголовки?

**Пример:** `Cache-Control: max-age=86400`

💡 **Подсказка:** Cache-Control + ETag/Last-Modified.

## Задание 3: Idempotency
POST /orders должен быть идемпотентным. Как клиент обеспечивает это?

**Пример:** `Передача Idempotency-Key на каждый повтор`

💡 **Подсказка:** Ключ идемпотентности в заголовке.
