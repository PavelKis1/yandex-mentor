# Лекция: 51 — Linux и Bash для бэкенд-разработчика

## Обзор темы
Операционная система Linux является стандартной средой выполнения серверных приложений. Уверенное владение командной строкой (Bash), утилитами фильтрации и удаленным доступом (SSH) — критический навык для каждого бэкендера.

---

## Подробный теоретический минимум

### 1. Основные утилиты анализа и фильтрации
- **`grep` / `ripgrep`**: поиск строк по паттернам и регулярным выражениям.
- **`awk` / `sed`**: потоковая обработка текста, парсинг логов и замена подстрок.
- **`curl` / `wget`**: выполнение HTTP-запросов из терминала для отладки API.
- **`jq`**: мощный инструмент командной строки для парсинга и фильтрации JSON.

---

## Производственный пример кода

Пример однострочника на Bash для поиска топ-5 IP-адресов с наибольшим числом запросов в файле логов:

```bash
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -n 5
```

---

## Анализ сложности (Big O)

- Утилиты командной строки оптимизированы на языке C для эффективной потоковой обработки больших файлов с минимальным потреблением памяти.

## Применение в Яндексе
- **Диагностика и отладка**: Подключение к подам и серверам по SSH, анализ логов в реальном времени, мониторинг системных ресурсов.
