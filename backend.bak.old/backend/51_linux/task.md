# Задания: Linux

## Задание 1: Навигация
Какие команды покажут: текущую папку, список файлов с правами, содержимое файла?

**Пример:** `pwd; ls -la; cat file.txt`

💡 **Подсказка:** Утилиты: pwd/ls/cat.

## Задание 2: Поиск и фильтр
Найдите все .py файлы в /app и посчитайте количество строк в каждом (find, wc).

**Пример:** `find /app -name '*.py' -exec wc -l {} \;`

💡 **Подсказка:** find + -exec.

## Задание 3: Права
Чем chmod 755 отличается от 644? Для какого типа файлов нужны 755?

**Пример:** `755: владелец rwx, группа/другие r-x; 644: rw- для всех`

💡 **Подсказка:** Категории: owner/group/other × r/w/x.
