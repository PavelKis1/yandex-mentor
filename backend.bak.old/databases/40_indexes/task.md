# Задания: Indexes

## Задание 1: Индекс по равенству
Таблица users(email). Запрос WHERE email='x@y.z' медленный. Что создать для ускорения?

**Пример:** `CREATE INDEX idx_users_email ON users(email);`

💡 **Подсказка:** B-tree индекс на колонку поиска.

## Задание 2: Композитный индекс
Запросы ищут по (country, city). Создайте подходящий индекс.

**Пример:** `CREATE INDEX idx_users_country_city ON users(country, city);`

💡 **Подсказка:** Порядок колонок: самый селективный первым.

## Задание 3: Влияние на запись
Объясните: почему много индексов ускоряют SELECT, но замедляют INSERT/UPDATE?

**Пример:** `INSERT обновляет все индексы; баланс чтение/запись`

💡 **Подсказка:** Каждый индекс = доп. структура на запись.
