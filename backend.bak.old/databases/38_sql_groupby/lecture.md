# Лекция: 38 — Группировка и агрегация (GROUP BY, HAVING, агрегатные функции)

## Обзор темы
Оператор `GROUP BY` позволяет объединять строки со схожими значениями в группы для выполнения вычислений и получения аналитических срезов (статистика, метрики, отчеты).

---

## Подробный теоретический минимум

### 1. Агрегатные функции
- **`COUNT(*)` / `COUNT(column)`**: подсчет количества строк (с учетом или без учета `NULL`).
- **`SUM(column)`**: суммирование числовых значений.
- **`AVG(column)`**: расчет среднего арифметического.
- **`MIN(column)` / `MAX(column)`**: поиск минимального и максимального значений.

### 2. Фильтрация групп (HAVING vs WHERE)
- **`WHERE`**: фильтрует исходные строки **до** группировки. Не может содержать агрегатные функции.
- **`HAVING`**: фильтрует уже готовые группы **после** агрегации. Здесь можно применять агрегатные функции (например, `HAVING COUNT(*) > 5`).

---

## Производственный пример кода

Пример запроса для поиска пользователей, сделавших заказов на общую сумму более 10 000 рублей:

```sql
SELECT 
    user_id,
    COUNT(id) AS total_orders,
    SUM(total_amount) AS total_spent
FROM orders
WHERE status = 'completed'
GROUP BY user_id
HAVING SUM(total_amount) > 10000
ORDER BY total_spent DESC;
```

---

## Анализ сложности (Big O)

| Операция | Временная сложность (Time) | Пространственная сложность (Space) | Описание |
|---|---|---|---|
| **GROUP BY (Hash Aggregate)** | $O(N)$ | $O(K)$ | $K$ — количество уникальных групп (требует памяти в RAM). |
| **GROUP BY (Sort Aggregate)** | $O(N \log N)$ | $O(1)$ | При предварительной сортировке по ключу группировки. |

---

## Применение в Яндексе
- **Аналитика и Метрики**: Подсчет ежедневной выручки, конверсии, количества активных пользователей и статистики поездок по регионам.
