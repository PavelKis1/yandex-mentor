# Задания: Redis

## Задание 1: Кэш с TTL
Напишите код: сохраните key 'user:1' со значением JSON и временем жизни 60 секунд (redis-py).

**Пример:** `r.setex('user:1', 60, json.dumps(user))`

💡 **Подсказка:** setex / SETEX с ttl.

## Задание 2: Счётчик просмотров
Реализуйте счётчик просмотров поста через INCR, без гонок.

**Пример:** `r.incr('post:5:views')`

💡 **Подсказка:** INCR атомарен — не нужны блокировки.

## Задание 3: Очередь через LPUSH/BRPOP
Реализуйте очередь на Redis: producer (LPUSH) и consumer (BRPOP с таймаутом).

**Пример:** `r.brpop('queue', timeout=0)`

💡 **Подсказка:** BRPOP блокирует; потребитель забирает справа.
