# Лекция: 39 — Оконные функции в SQL (Window Functions)

## Обзор темы
Оконные функции выполняют расчеты по набору строк таблицы (окну), которые связаны с текущей строкой. В отличие от `GROUP BY`, оконные функции **не сжимают** строки в одну группу, а сохраняют исходную детализацию записей.

---

## Подробный теоретический минимум

### 1. Синтаксис
`function_name() OVER (PARTITION BY partition_col ORDER BY sort_col)`
- **`PARTITION BY`**: разбивает строки на группы (окна), внутри которых производятся вычисления (аналог `GROUP BY` для окон).
- **`ORDER BY`**: задает порядок строк внутри каждого окна.

### 2. Основные функции
- **`ROW_NUMBER()`**: присваивает каждой строке уникальный порядковый номер внутри раздела.
- **`RANK()`**: ранжирует строки с пропусками при одинаковых значениях (например, `1, 2, 2, 4`).
- **`DENSE_RANK()`**: ранжирует строки без пропусков (например, `1, 2, 2, 3`).
- **`LAG()` / `LEAD()`**: обращение к значению предыдущей или следующей строки в окне.

---

## Производственный пример кода

Пример запроса для поиска топ-3 последних заказов каждого пользователя с помощью `ROW_NUMBER`:

```sql
WITH ranked_orders AS (
    SELECT 
        id,
        user_id,
        total_amount,
        created_at,
        ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY created_at DESC) as rn
    FROM orders
)
SELECT id, user_id, total_amount, created_at
FROM ranked_orders
WHERE rn <= 3;
```

---

## Анализ сложности (Big O)

| Операция | Временная сложность (Time) | Описание |
|---|---|---|
| **Window Functions** | $O(N \log N)$ | Требует сортировки данных по ключам `PARTITION BY` и `ORDER BY`. |

---

## Применение в Яндексе
- **Анализ поведения пользователей**: Поиск последних транзакций, вычисление скользящих средних, нахождение топ-N элементов в категориях (например, топ товаров в каждой категории Маркета).
