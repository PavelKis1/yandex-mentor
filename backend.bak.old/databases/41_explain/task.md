# Задания: Explain

## Задание 1: Чтение EXPLAIN
Дан EXPLAIN SELECT ... FROM users WHERE age > 30; Как определить, что есть полный скан таблицы?

**Пример:** `type = ALL в плане`

💡 **Подсказка:** Ищи 'type: ALL' (seq scan).

## Задание 2: Использование индекса
Почему запрос с LIKE '%text%' не использует обычный индекс на колонке?

**Пример:** `LIKE с ведущей звездой — не сработает btree`

💡 **Подсказка:** Полнотекстовый поиск / GIN для подстрок.

## Задание 3: Оптимизация по плану
EXPLAIN показывает 'Seq Scan' на миллионной таблице с WHERE по колонке x. Что сделать?

**Пример:** `Добавить индекс на x и перезапустить ANALYZE`

💡 **Подсказка:** Индекс + VACUUM ANALYZE.
