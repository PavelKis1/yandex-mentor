# Задания: Transactions

## Задание 1: Потерянное обновление
Две транзакции одновременно увеличивают balance на 10. Опишите проблему и решение (BEGIN/COMMIT/ISOLATION).

**Пример:** `Свойство атомарности: UPDATE ... SET balance=balance+10 атомарно`

💡 **Подсказка:** Одиночная UPDATE атомарна; массивы обновлять через row lock.

## Задание 2: Откат
В транзакции: INSERT, INSERT с ошибкой. Что останется после ROLLBACK?

**Пример:** `Ничего: обе вставки откатятся`

💡 **Подсказка:** ROLLBACK отменяет всю транзакцию.

## Задание 3: Уровни изоляции
Чем READ COMMITTED отличается от REPEATABLE READ? Приведите пример, когда результат различается.

**Пример:** `При RC повторные чтения видят чужие коммиты`

💡 **Подсказка:** Опиши ситуацию с двумя соединениями.
