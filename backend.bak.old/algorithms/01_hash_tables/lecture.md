# 📖 Лекция 01: Хеш-таблицы (Hash Tables)

## Что это и зачем в контесте

`dict` и `set` в Python — это хеш-таблицы. Они дают O(1) на поиск, вставку, удаление. Без этого знания ~30% задач в контесте Яндекса решаются медленно (O(n²) вместо O(n)) и не проходят по времени.

## Теория (кратко)

Хеш-таблица = массив корзин + хеш-функция (`hash(key) % size`). Когда ключ попадает в корзину, Python быстро находит значение. Коллизии возможны, но Python использует открытое хеширование с переадресацией, поэтому сложность остаётся O(1) в среднем.

## Базовый код

```python
from collections import defaultdict, Counter

# dict: поиск по ключу O(1)
prices = {"apple": 50, "banana": 30}
prices.get("melon", 0)  # 0 — безопасно

# set: проверка "уже видели"
seen = set()
seen.add(1)
1 in seen               # True, O(1)

# defaultdict: счётчик без KeyError
counts = defaultdict(int)
for x in [1, 2, 1, 3]:
    counts[x] += 1     # не упадёт

# Counter: частоты
c = Counter("hello")
print(c.most_common(2))  # [('l', 2), ('h', 1)]
```

## Правила ключей

Ключ должен быть хешируемым (`hashable`). Можно: `int`, `str`, `tuple`. Нельзя: `list`, `dict`, `set`. Проверить: `hash(x)` не бросает исключение.

```python
# ❌ list как ключ — ошибка
d = {}
d[[1, 2]] = "x"     # TypeError: unhashable type: 'list'

# ✅ tuple как ключ
d[(1, 2)] = "x"
```

## Когда использовать

- Подсчёт частот (`Counter`)
- Проверка дубликатов (`set` или `len(set) != len(arr)`)
- Поиск дополнения (`dict` в Two Sum)
- Кэш результатов
- Дедупликация (`set` или `dict.fromkeys`)

## Сложность

| Операция | Среднее | Худшее |
|----------|--------|--------|
| Поиск `d[k]` | O(1) | O(n) |
| Вставка | O(1) | O(n) |
| Удаление | O(1) | O(n) |
| Перебор | O(n) | O(n) |

## Вопросы на собеседовании в Яндексе

1. «Расскажите про сложность dict в Python» → O(1) средний, O(n) худший (коллизии)
2. «Можно ли использовать list как ключ?» → Нет, нужен tuple
3. «Чем Counter отличается от dict?» → Под капотом тот же dict, но методы `.most_common()`, `.elements()`
4. «Как устроен set?» → Та же хеш-таблица, но без значений
