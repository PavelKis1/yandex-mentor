# Задания: Хеш-таблицы

## Задание 1: Два числа (Two Sum)
Дан массив nums и целое число target. Верните индексы двух чисел, сумма которых равна target.

## Задание 2: Группировка анаграмм
Дан массив строк strs. Сгруппируйте анаграммы вместе.

## Задание 3: Подмножество с суммой
Дан массив nums и целое число k. Найдите количество подмножеств с суммой k.
